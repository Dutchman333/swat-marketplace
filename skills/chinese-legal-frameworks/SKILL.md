# Chinese Legal Frameworks

Methodology and decision frameworks for PRC legal advisory. Reusable across both Scenario 1 (Company) and Scenario 2 (Personal). Designed to be loaded once at the start of each operation and referenced throughout.

## Use When

- Building a legal Q&A / 风险评估 / 合同审查 / 案例综述 deliverable that needs an explicit decision rationale
- Picking among 谈判 / 调解 / 仲裁 / 诉讼 / 报警 paths
- Drafting 律师函 / 申请书 / 通知函 / 协议草稿 / 答辩状 / 异议书
- Surfacing all relevant prescription / arbitration / 工伤认定 / 行政复议 time limits in a deliverable
- Assessing 跨地域 differences before committing to a single conclusion

## The 4-Dimension Risk Matrix

Every PRC legal risk falls into one or more of 4 dimensions. Score each dimension 0-10 and color-code (≤3 = green, 4-6 = amber, 7-10 = red, criminal = always red + purple sidebar).

| Dimension | What it covers | Severity floor | Severity ceiling |
|---|---|---|---|
| **合规 风险** (Compliance) | 行政许可 / 备案 / 强制标准 / 行业 监管 / 行政罚款 / 行政处罚 | 警告 + 罚款 | 暂停 / 吊销 / 责令停业 |
| **民事 风险** (Civil) | 合同 违约 / 侵权 / 损害赔偿 / 婚姻 财产 / 继承 / 物权 | ¥0 | 个人 / 公司 资产 全部 强制执行 |
| **行政 风险** (Administrative) | 工伤认定 / 劳动监察 / 环保 / 安全 / 税务 / 市场监管 | 行政警告 | 行政拘留 / 责令停产 |
| **刑事 风险** (Criminal) | 拒不支付劳动报酬 / 重大责任事故 / 污染环境 / 商业秘密 / 个人信息 / 妨害公务 / 等 | (none — 任何 刑事 都是 顶格) | 自由刑 + 财产刑 + 资格刑 + 社会信用 |

**Output format**:
```
## 风险评估矩阵

| 维度 | 概率 | 影响 | 综合评分 | 颜色 | 缓解 优先级 |
|---|---|---|---|---|---|
| 合规 | 高 | 中 | 7/10 | 红 | P0 |
| 民事 | 中 | 高 | 7/10 | 红 | P0 |
| 行政 | 低 | 中 | 4/10 | 橙 | P1 |
| 刑事 | 低 | 极高 | 5/10 | 紫 | P0 |
```

**Cross-dimensional triggers**:
- 同时 触发 ≥3 维度 → 综合 高风险, 必须 推荐 执业律师
- 触发 刑事 → 必须 立即 推荐 执业律师 + 红色 banner
- 单维度 ≥9 → 视为 全报告 红色等级

## The 20-Point Contract Review Checklist

Apply to every 合同审查 brief. Each point gets red / amber / green tag + 1-line note + redline suggestion.

| # | Section | Check | Common red flags |
|---|---|---|---|
| 1 | 主体 | 双方 主体 是否 适格 (营业执照 / 身份证 一致; 法定代表人 / 授权代理 真实) | 用 个人 名义 但 实质 公司业务; 营业执照 已注销 |
| 2 | 标的 | 标的 是否 明确 / 合法 / 可履行 | 标的 描述 模糊; 标的 涉及 限制 / 禁止 流通 物 |
| 3 | 数量 + 质量 | 数量 / 规格 / 质量 标准 是否 明确 | "符合 行业标准" 但 行业标准 不存在 / 多版本 |
| 4 | 价款 / 报酬 | 总金额 / 单价 / 含税 / 货币 / 计算公式 | 含税 / 不含税 不明; 汇率 浮动 未约定 |
| 5 | 履行 期限 | 期限 / 起算点 / 节点 | "尽快" / "合理时间" 等 模糊表述 |
| 6 | 履行 方式 | 交付 地点 / 方式 / 验收 | 风险转移 节点 不明 |
| 7 | 履行 顺序 | 先后履行 / 同时履行 | 顺序 反向 (e.g. 先付款 后交货) |
| 8 | 验收 / 异议期 | 验收 标准 + 时限 + 异议方式 | 异议期 ≤ 商业 合理 |
| 9 | 包装 / 运输 / 保险 | 责任划分 (CIF / FOB / Ex Works 等 — INCOTERMS) | 责任归属 模糊 |
| 10 | 知识产权 | 归属 / 许可 / 限制 / 第三方 侵权 担保 | "默认 归 委托方" 但 委托方 未付清 |
| 11 | 保密 | 范围 / 期限 / 例外 / 违反 责任 | 保密期限 永久 (不合理); 违约金 过低 |
| 12 | 违约 责任 | 违约金 / 损失赔偿 / 解除 / 实际履行 | 违约金 30% 以上 (法院 可能调减); 单方 解除 条件 一边倒 |
| 13 | 不可抗力 | 范围 + 通知 + 证明 + 损失 分担 | 范围 过宽 / 过窄; 通知期限 不合理 |
| 14 | 争议 解决 | 协商 → 调解 → 仲裁 OR 诉讼; 管辖法院 | 仲裁 + 诉讼 二选一 时 应明确 (一旦 选 仲裁 = 排除 法院 管辖) |
| 15 | 法律 适用 | 中国法律 vs 外国法律 / 国际公约 | 跨境 合同 漏 选择 法律 → CISG / 冲突法 default |
| 16 | 合同 生效 | 签字 / 盖章 / 登记 / 备案 / 批准 | 国有 / 中外合资 等 部分合同 必须 备案 / 批准 才生效 |
| 17 | 合同 变更 / 解除 | 协商 + 法定 + 约定 — 程序 / 通知 / 时效 | 单方 任意 解除 — 不合理 |
| 18 | 附件 + 优先顺位 | 主合同 vs 附件 vs 补充协议 优先级 | 多份 文件 之间 冲突 时 优先 不明 |
| 19 | 通知 / 送达 | 地址 / 邮箱 / 微信 / 短信 / 时点; 退回 / 拒收 处理 | 仅 写 公司 地址 + 实际 已搬 → 送达 失效 |
| 20 | 签署 + 用印 | 签字 + 盖章 (公章 / 合同章 / 财务章 / 法人章 区别) + 日期 + 见证 | 仅 签字 没盖章 — 公司 主张 无效 风险 |

**Output format**:
```
## 合同 逐条 审查

### Article N — [topic]
**评级**: 🔴 / 🟡 / 🟢
**问题**: [specific issue]
**法条**: [民法典 第N条 / 司法解释 第N条]
**修改建议**: [redline language]
**谈判 backup**: [若 对方 不接受, 退而求其次 的 表述]
```

## 6+ Document Drafting Templates

### Template 1 — 律师函 (Demand Letter)

```
[抬头: 致 [对方公司 / 个人] 全名]
[抄送: 必要时]

[标题: 关于 [事项] 的 律师函]

[正文 5 段]:
1. 函 的 委托方 + 委托 律师 / 律师事务所 / 执业证号 (确认 律师 资格)
2. 事实 经过 (时间 / 地点 / 当事方 / 关键 行为, 简要 + 完整)
3. 法律 分析 (适用 法律 / 法条 / 案例)
4. 主张 / 要求 + 期限 (限 收到本函 [N] 日内 履行; 超期 后果)
5. 后续 程序 (起诉 / 仲裁 / 报案 / 控告 等); 保留 一切 法律权利

[落款: 律师事务所 + 律师 签字 + 日期]
[附: 委托书 + 律师执业证 复印件]
```

> **Squad-internal 替代**: 如 操作员 没有 律师, 可改为 [当事人 函] (以当事人 自己 名义 + 没有 律师执业证 部分). 效力 略低 但 仍 起到 主张 + 中断 时效 的 法律效果.

## Case Research Methodology — 5-Step

### Step 1: Build the Search Query (China Wenshu / 北大法宝)
```
关键词组合 = (案由 / 案件 类型) + (法条 / 法律名称 + 条号) + (地区 — 优先 江苏 / 苏州) + (年份 — 近 3-5 年优先) + (审判程序 — 一审 / 二审 / 再审 / 仲裁) + (法院级别 — 中级 / 高院 / 最高院 优先)
```

### Step 2: 5-Source De-noising Filter
| Source rank | Use first | Reliability ★ |
|---|---|---|
| 1 | 最高院 指导性案例 / 公报案例 | ★★★★★ |
| 2 | 高院 公报案例 / 江苏 高院 系列 案件 | ★★★★ |
| 3 | 中院 / 基层法院 生效判决 (优先 江苏 / 苏州) | ★★★ |
| 4 | 学术 评论 / 教科书 / 法学期刊 | ★★ |
| 5 | 律所 / 法律网站 案例分析 | ★ |

### Step 3: 同案 对比 表
```
| 案号 | 法院 | 年份 | 案件 类型 | 关键事实 | 法律 关键问题 | 法院 裁判 思路 | 判决结果 | 与本案 异同 | 启示 |
|---|---|---|---|---|---|---|---|---|---|
| (2024)苏05民终xxxx | 苏州中院 | 2024 | 劳动争议 | ... | ... | ... | ... | ... | ... |
```

### Step 4: 法院 倾向 trend-line
统计 近 3 年 同类案件 (≥10 件), 计算:
- 原告 (员工 / 个人) 胜诉率
- 被告 (单位 / 对方) 胜诉率
- 调解率
- 适用 法条 / 司法解释 频次
- 法院 整体 倾向 (严 / 宽 / 中)

### Step 5: Devil's Advocate — 反向 案例
每个 主推论证 → 至少 找 1-2 件 反向 案例 (法院 持 不同 意见). 在 报告中 列出, 说明 区别要素 + 风险.

## Path Decision Tree — 谈判 / 调解 / 仲裁 / 诉讼 / 报警

```
争议 出现
   │
   ├── 涉及 刑事 (e.g. 拒不支付劳动报酬罪 / 重大责任事故罪 / 商业秘密罪 / 等)?
   │     YES → 报警 优先 + 同步 民事 起诉; 立即 推荐 执业 刑事 律师
   │     NO → 继续
   │
   ├── 涉及 行政 (工伤认定 / 行政许可 / 行政罚款 异议)?
   │     YES → 行政复议 (60 日内) → 行政诉讼 (6 个月内); 同步 民事 起诉 (若 涉及 民事 损失)
   │     NO → 继续
   │
   ├── 关系 是否 长期 / 重要 + 双方 都有 让步 意愿?
   │     YES → 协商 / 调解 优先; 专业 调解 (法院 调解 / 商会 调解 / 律师 调解); 调解 协议 OR 司法 确认 取得 强制执行力
   │     NO → 继续
   │
   ├── 标的 / 主体 — 劳动 争议?
   │     YES → 劳动 仲裁 必经 (前置); 不服 仲裁 → 起诉 (15 日内)
   │     NO → 继续
   │
   ├── 合同 中 有 仲裁 条款?
   │     YES → 商事 仲裁 (CIETAC / 北京仲裁委员会 / 上海仲裁委员会 / 深圳国际仲裁院 / 苏州仲裁委员会); 一裁 终局; 不能 起诉 (除非 撤销 仲裁裁决 — 严苛)
   │     NO → 继续
   │
   └── 默认: 民事 诉讼
        ├── 一审 (基层 / 中级)
        ├── 二审 (终审)
        └── 再审 (有限)
```
