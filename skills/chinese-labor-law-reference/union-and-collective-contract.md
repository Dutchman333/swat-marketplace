# Union and Collective Contract — Practitioner Reference

> Statutes referenced:
> - 《中华人民共和国工会法》 (1992 enacted, 2001 / 2009 / 2021 amendments — current effective version 2021-12-24 修正)
> - 《中华人民共和国劳动合同法》 第五章 第二节 集体合同 (第51-56条)
> - 《集体合同规定》 (劳动和社会保障部第22号令, 2004-05-01 施行)
> - 《工资集体协商试行办法》 (劳社部 [2000] 9 号)
> - 《女职工权益保护专项集体合同》 / 《工资专项集体合同》 — derivative special-topic collective contracts

## Union Formation Threshold

工会法 第10条: 企业 / 事业单位 / 机关 有 **会员 25 人以上** 的 → 应当 建立 基层工会委员会; 不足 25 人 的, 可以单独建立, 也可以由两个以上单位的 会员 联合建立, 也可以选举 组织员 一人, 组织 会员开展活动.

**For the operator's group** (~700 employees across 3 companies): each individual company is well above 25 → each company **must** establish 基层工会委员会; group level may also have 工会联合会.

## Union's Statutory Functions (工会法 第6-7条)

主要职能:
1. 维护职工合法权益
2. 组织 / 教育 职工 依法行使民主权利
3. 协调劳动关系
4. 集体协商 + 签订 集体合同
5. 监督 用人单位 遵守 劳动法律
6. 组织职工 参加 民主管理 + 民主监督
7. 协助 党政 处理 突发事件
8. 促进 企业发展

## Collective Contract — 5 Types

劳动合同法 + 集体合同规定:

| Type | Source | Coverage |
|---|---|---|
| **综合性 集体合同** | 劳动合同法第51条 | 工资 / 工时 / 休息休假 / 劳动安全卫生 / 保险福利 / 等 |
| **工资 专项 集体合同** | 工资集体协商试行办法 | 工资 调整 / 加班费 / 奖金分配 / 等 |
| **女职工权益 专项 集体合同** | 女职工保护规定 + 妇女权益保障法 2022 修订 | 三期 保护 / 哺乳室 / 性骚扰防治 / 等 |
| **劳动安全卫生 专项 集体合同** | 安全生产法 + 集体合同规定 | 安全防护 / 工伤预防 / PPE / 等 |
| **行业 / 区域 集体合同** | 劳动合同法第53-54条 | 行业 / 区域 内 多家单位 共同签订 |

## Collective Contract Negotiation Process

```
工会 (代表职工方) ←→ 单位
   │
   ├── 协商代表 资格确认 (工会代表 + 单位代表, 双方 人数对等, 通常 3-9 人)
   │
   ├── 提出 集体协商 要求 (任何一方; 5 日内 答复, 不得拒绝)
   │
   ├── 协商 (≥1 次, 实务 多 3-5 次)
   │
   ├── 草案 → 职工代表大会 OR 全体职工讨论通过 (过 1/2)
   │
   ├── 签订 集体合同 → 双方 法定代表人 签字盖章
   │
   ├── 报送 劳动行政部门 → 自报送 15 日内 未提出异议 → 生效
   │
   └── 公示 全体职工
```

## Collective Contract — Legal Effect

劳动合同法第55条: "**集体合同中劳动报酬和劳动条件等标准不得低于当地人民政府规定的最低标准; 用人单位与劳动者订立的劳动合同中劳动报酬和劳动条件等标准不得低于集体合同规定的标准.**"

**Hierarchy** (高 → 低):
1. 法律 / 行政法规 (劳动法 / 劳动合同法)
2. 当地最低标准 (最低工资 / 最低社保等)
3. **集体合同 标准** (high water mark for the unit)
4. 个人劳动合同 标准 (≥ 集体合同)

任何 个人合同 标准 < 集体合同 → 个人合同 该条款 无效, 适用 集体合同 标准.

## Union's Procedural Rights — Termination Notification

劳动合同法第43条: "用人单位单方解除劳动合同, 应当事先将理由通知工会. 用人单位违反法律、行政法规规定或者劳动合同约定的, 工会有权要求用人单位纠正. 用人单位应当研究工会的意见, 并将处理结果书面通知工会."

**程序**: 单位 单方 解除 (第39 / 40 / 41 条) 任何员工 → **必须 事先 通知 工会**. 漏通知 = 程序违法.

**司法解释一 第48条**: "用人单位在劳动合同解除或者终止后, 起诉前 补正 通知工会 程序的, 人民法院 可以 视为 已通知." → 漏通知 可在 起诉前 补正; 但 已起诉 则 难以 补救.

**实务**: 苏州 / 江苏 倾向 严格 — 单位 应在 解除 前 5 日 书面通知 工会, 留存 送达 证据 (签收 / 邮政挂号).

## Special Collective Contract — Female Employees (女职工权益专项集体合同)

操作员 厂区 (印染) — 女职工 比例 通常 40-60% — 必备.

应包含:
- 三期 保护 + 调岗 待遇
- 哺乳室 (女职工 ≥100 人 单位 应建)
- 健康检查 (孕前 / 孕期 / 哺乳期)
- 化学品接触 限制 (重要: 印染 染料 / 助剂)
- 高温 / 噪声 / 粉尘 接触 限制
- 性骚扰 防治机制 (妇女权益保障法 2022 修订 第25条 — 单位 防治 性骚扰 法定义务)

## Worker Representative Congress (职工代表大会, 职代会)

公司法 第18条 + 工会法 第38条 + 各地 职代会条例:

**Functions**:
- 听取 + 审议 单位 重大 决定 (规章制度 / 重大改革 / 重大经营事项)
- 审议 通过 集体合同 草案
- 监督 单位 遵守 劳动法律
- 评议 高管

**与 规章制度 关联**: 劳动合同法第4条 + 司法解释一第50条 — 直接涉及 劳动者 切身利益 的 规章制度 (劳动报酬 / 工时 / 休假 / 劳动定额 / 安全卫生 / 保险福利 / 培训 / 纪律 / 等), **必须 经 职代会 OR 全体职工 讨论, 提出方案和意见, 与 工会 OR 职工代表 平等协商确定**.

漏 民主程序 → 规章 不能 作为 解除 / 处罚 依据.

## High-Frequency Pitfalls

| Pitfall | Frequency | Consequence | Mitigation |
|---|---|---|---|
| 25 人 以上 单位 未建工会 | High | 行政责令 + 不能 集体协商 → 劳动关系 张力增加 | 6 个月内 建会; 申报 总工会 |
| 解除员工 未事先通知工会 | High | 程序违法 — 视情形可能 视为 违法解除 OR 起诉前 补正 (但 已起诉 难补) | 解除 前 5 日 书面通知 工会; 留证 |
| 规章制度 漏 职代会 / 全员 程序 | High | 不能作为 解除 / 处罚 依据 | 重大规章 → 职代会 投票 → 公示 → 员工签收 |
| 集体合同 标准 < 法定最低 | Medium | 该条款 无效 | 起草前 比对 当地最低 |
| 个人合同 工资 < 集体合同 工资 | Medium | 个人合同 工资 条款 无效, 适用 集体合同 | 个人合同 ≥ 集体合同 |
| 职代会 形式化 (走过场, 无 实际投票) | Medium | 民主程序 真实性 受质疑 | 留 会议纪要 / 投票记录 / 出席签到 |
