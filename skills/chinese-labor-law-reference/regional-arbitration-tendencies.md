# Regional Arbitration Tendencies — Practitioner Reference

> Caveat: All tendencies below reflect practitioner-observed patterns from generally available case databases (中国裁判文书网) and provincial high-court bulletins (省高院公报) up to early 2026. Individual cases vary; this is not a substitute for searching wenshu.court.gov.cn for the specific 法院 + 案由 before issuing a verdict. **Always cross-check the latest 5 cases on the same issue before relying on any tendency stated here.**

## Why Region Matters in PRC Labor Law

PRC 劳动合同法 + 调解仲裁法 are uniform national statutes, but four mechanisms create regional variance:
1. **Provincial implementation rules** (e.g., 《江苏省劳动合同条例》 / 《江苏省工资支付条例》) fill gaps and adjust standards.
2. **Provincial-high-court guiding opinions** ("会议纪要" / "审委会意见") interpret ambiguous national-level provisions.
3. **Arbitration commission internal handling rules** vary by city.
4. **Local economic context** (Suzhou as 高人均GDP 制造业聚集 region; Shenzhen as flexible-employment hub) shapes 倾向 on issues like 末位淘汰 and 项目制 contracts.

## High-Stakes Issue Comparison (Yangtze-Delta vs Pearl-River-Delta vs Beijing-Tianjin)

### Issue 1: 加班费 计算 基数

| Region | Tendency | Cite |
|---|---|---|
| 苏州 / 南京 / 无锡 | 严格 — 按 合同约定工资 OR 应得工资 (实际工资) 全口径; 不能 仅按 基本工资 | 江苏省高院 2010 江苏省高级人民法院 关于审理劳动争议案件的指导意见 |
| 上海 | 中 — 合同约定 OR 应得; 但 部分 法院 接受 不超过 70% 应得 (论证 必要) | 上海高院 系列指导意见 |
| 杭州 / 宁波 (浙江) | 中 — 合同约定 OR 应得 |
| 广州 | 偏宽容 单位 — 历史上 高院 倾向 70% 应得; 近年 收紧 | 广东省高院 |
| 深圳 | 严格 — 合同约定 OR 应得 全口径 |
| 北京 | 严格 — 合同约定 优先, 不明 → 应得 70% (北京 高院倾向) |
| 天津 | 中 |

**Practitioner inference (Suzhou)**: 加班费 基数 仲裁 审查 严, 单位 风险高 — 应按 应得工资 全口径 计算.

### Issue 2: 经济补偿 N 计算 基数

劳动合同法第47条第3款: "本条所称月工资是指劳动者在劳动合同解除或者终止前十二个月的平均工资."

**关键争议**: 平均工资 包含 哪些项目?

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | **应得 全口径** 含: 基本工资 + 岗位工资 + 绩效 + 奖金 + 津贴 + 加班费 (部分 法院 含, 部分 不含); 高温津贴 含 |
| 上海 | 应得; 但 高院 部分意见 倾向 不含 加班费 (因 加班费 非常态收入) |
| 广州 / 深圳 | 应得; 加班费 是否含 看 是否 常态 (常态化 加班 → 含; 偶发 → 不含) |
| 北京 | 应得; 但 福利补贴 / 报销 不含 |

**Practitioner inference (Suzhou)**: 单位 应 按 应得 全口径 (含 高温 / 夜班 / 加班 — 取保守口径); 实际仲裁 时 可争 加班费 是否 计入.

### Issue 3: 三期女职工 保护

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | 严格 — 解除 证据要求 极高; 调岗 待遇 必须 维持; 哺乳期 婴儿 1 周岁 当日 仍受保护 |
| 上海 | 严格 |
| 浙江 | 严格 |
| 广东 | 偏严 单位 (深圳 极严; 广州 较严; 东莞 / 佛山 中) |
| 北京 | 严格 |

**Practitioner inference**: 全国 三期 保护 标准 接近. 单位 试图 通过 末位 / 不胜任 解除 三期员工 → 几乎全输.

### Issue 4: 末位淘汰 / 强制 末位 解除

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | **不支持** — 末位 ≠ 不胜任; 第40条 "不胜任" 必须 客观标准 + 培训 / 调岗 程序 (江苏省高院 2010 意见 + 司法解释一第48条) |
| 上海 | 不支持 — 上海高院 明确 |
| 浙江 | 不支持 |
| 广东 | 不支持 (深圳 / 广州 高院 明确) |
| 北京 | 不支持 (北京高院 多次重申) |

**Practitioner inference**: 末位淘汰 制度 全国 实务 一致 不支持; 单位 用 末位 解除 = 违法解除 = 第48条 2N.

### Issue 5: 调岗 调薪 单方变更

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | 严 — 单位 单方 调岗 须 (a) 客观必要性 + (b) 合理性 (待遇 不降 / 距离 不远 / 与原岗位 关联) + (c) 协商; 不满足 → 视为 单方变更 → 员工被迫离职 + 经济补偿 |
| 上海 | 中 — 客观情况 重大变化 + 协商不一致 → 单位 可解除; 单纯 调岗 仍受 三要素 检验 |
| 浙江 | 严 |
| 广东 | 中 — 偏中性 |
| 深圳 | 严 |
| 北京 | 严 |

**Practitioner inference**: 调岗 必须 协商 + 书面 + 留证. 单方 一刀切 → 高败诉率.

### Issue 6: 工伤 补充协议 (单位 + 员工 私下 一次性 买断)

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | 鉴定后 + 显失公平 标准 较严 — 协议金额 明显低于 法定待遇 → 部分支持员工撤销; 鉴定前 一次性买断 → 通常 无效 |
| 上海 | 同 |
| 浙江 | 同 |
| 广东 | 中 — 鉴定后 协议 一般 有效 (除非 极端低于 法定) |
| 北京 | 严 — 严格按 法定 待遇 + 协议 仅作 补充 |

**Practitioner inference**: 工伤后 协议 必须 等 工伤认定 + 劳动能力鉴定 完成 后 谈; 协议 金额 ≥ 法定 待遇 (一次性伤残补助金 + 一次性工伤医疗补助金 + 一次性伤残就业补助金) 才能 大概率 有效.

### Issue 7: 未签 劳动合同 二倍工资 时效起算

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | 按月 起算 — 每月 应付 二倍工资 时 1 年时效 起算; 12 个月 二倍工资 仅追近 12 月 (实际可获 11 个月) |
| 上海 | 同 |
| 浙江 | 同 |
| 广东 | 同 |
| 北京 | 同 |

**Practitioner inference**: 全国 一致 — 单位 拖到 11 个月 再 签合同 + 12 月 起 仲裁 → 员工 几乎 能获全部 11 月 二倍工资 差额.

### Issue 8: 试用期 薪资 + 时长

| Region | Tendency |
|---|---|
| 全国 | 严 — 第19 / 20条 是 hard rule; 实务一致 |

**Practitioner inference**: 单位 容易 错的: (a) 重复试用 (一次为限); (b) 试用期 工资 < 80% 合同工资 OR < 当地 最低工资.

### Issue 9: 规章制度 程序合法性

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | 严 — 必须 (a) 经 职代会 / 工会 / 全体员工 民主程序; (b) 公示 (员工签收 / OA / 公告 至少一种); 缺一 → 不能作为 解除 依据 (司法解释一第50条) |
| 上海 | 严 |
| 浙江 | 严 |
| 广东 | 严 |
| 北京 | 严 |

**Practitioner inference**: 全国 一致. 单位 若依据 规章 解除 → 必须 提交 (a) 民主程序 证据 (会议纪要 / 签到 / 表决) + (b) 公示证据 + (c) 员工 签收/知悉 证据.

### Issue 10: 项目制 / 灵活用工 + 实质 劳动关系

| Region | Tendency |
|---|---|
| 苏州 / 江苏 | 中 — 看 实质 (考勤 / 工资发放周期 / 工作场所 / 业务关联性); 灵活用工 平台 派单, 但 实际 长期 全职 → 倾向 认定 劳动关系 |
| 深圳 | 偏宽 — 灵活用工 接受度 较高 |
| 北京 | 严 — 实质 优先 |

**Practitioner inference (印染 行业)**: 厂里 长期 工人, 即使 套用 劳务派遣 / 业务外包 / 项目制 → 实质 仍是 劳动关系 → 仲裁 + 一审 倾向 认定 直接 劳动关系.

## Tactical Implications for the Operator (your-region industrial group employer side)

| Tactic | When to apply |
|---|---|
| 调解 优先 (<your-region> 仲裁院 强制 调解 阶段) | 90% 拖欠工资 / 加班费 / 经济补偿 类型 — 调解金额 通常 8-9 折 法定; 单位代价 比 全输 仲裁裁决 + 25%加付 低 |
| 主动 提供 完整考勤 + 工资记录 | 单位掌管证据 — 不提供 → 推定员工主张; 主动提供 + 自证清白 = 较好策略 |
| 三期 / 工伤 / 医疗期 员工 — 不解除, 等保护期满 | 几乎 100% 败诉 → 调解金额会更高 → 直接 等期满 + 协议解除 + 法定补偿 |
| 末位淘汰 / 不胜任 解除 — 需 严格证据链 | 业绩考核标准 (民主程序 + 公示) + 当事人考核记录 + 培训 / 调岗 程序证据 + 仍不胜任证据 + 工会通知 + 解除送达 — 缺一 = 违法解除 |
| 工伤补充协议 — 等 鉴定后 + 协议金额 ≥ 法定 | 鉴定前 买断 = 大概率 无效; 鉴定后 + 协议金额 ≥ 法定 → 较稳 |
