# Labor Contract Law — Practitioner Reference

> Statute: 《中华人民共和国劳动合同法》(2007 enacted, 2012 amendment) + 《劳动合同法实施条例》(2008)
> Verify version: 现行有效, latest text: 全国人大常委会 2012-12-28 修正决定; current effective version retrievable at flk.npc.gov.cn.

## Article Map (high-frequency)

| Article | Topic | Practitioner one-liner |
|---|---|---|
| 第7条 | 劳动关系建立时间 | 用工之日起 (NOT 合同签订之日); employer must register within 30 days |
| 第10条 | 书面合同义务 | 用工之日起 1 个月内必须签 |
| 第14条 | 无固定期限合同 | 连续工作满 10 年 OR 连续订立 2 次固定期限合同 → 必须签无固定期限 (员工申请) |
| 第17条 | 必备条款 | 9 项必备条款，缺项可能导致条款无效 |
| 第19条 | 试用期上限 | ≤3M = no probation; 3M-1Y ≤ 1M; 1Y-3Y ≤ 2M; ≥3Y or 无固定期 ≤ 6M; 一次试用为限 |
| 第20条 | 试用期工资底线 | 不低于本岗位最低工资 OR 合同工资 80%; 且不低于当地最低工资 |
| 第22条 | 培训服务期 + 违约金 | 出资专项培训才能约定服务期; 违约金不超过培训费用; 按未履行年限折算 |
| 第23-24条 | 竞业限制 | 期限不超过 2 年 (限定 6 类人); 必须按月支付经济补偿 (无补偿则条款不生效, 司法解释一第36条) |
| 第26条 | 合同无效情形 | 欺诈胁迫 / 用人单位免责加员工责任 / 违法 |
| 第31条 | 加班限制 | 严格限制延长工作时间，应当保障身体健康 |
| 第36条 | 协商解除 | 双方平等协商一致 — 没有限制 |
| 第37条 | 员工辞职 | 提前 30 日书面通知 (试用期 3 日); 不需要单位同意 |
| 第38条 | 员工被迫辞职 | 6 类情形(欠薪/欠社保/未提供条件/规章违法/合同无效/其他) → 员工解除 + 经济补偿 |
| 第39条 | 用人单位过错性解除 | 6 类(试用期不符合 / 严重违纪 / 严重失职 / 双重劳动关系 / 合同无效 / 刑责) → 无补偿 |
| 第40条 | 用人单位无过错性解除 | 3 类(医疗期满 / 不胜任 / 客观情况重大变化) → 提前 30 日书面通知 OR 多支付 1 个月工资 (代通知金) + 经济补偿 |
| 第41条 | 经济性裁员 | 裁 ≥20 人 OR 裁员占 ≥10% → 提前 30 日向工会说明 + 报告劳动行政部门 + 优先留用 |
| 第42条 | 不得解除情形 | 6 类(职业病 / 工伤 / 医疗期 / 三期 / 工龄≥15且离退休<5 / 法律其他) → 40/41 条不得使用; 39 条仍可 |
| 第43条 | 工会程序 | 单方解除应事先通知工会; 漏通知 = 程序违法 (但通常可补正; 司法解释一第48条) |
| 第46条 | 经济补偿支付情形 | 7 大类: 38 条被迫离职 / 36 条单位提出协商解除 / 40 条单位单方解除 / 41 条裁员 / 客观无法续订 / 公司破产解散 / 其他 |
| 第47条 | 经济补偿计算 | N (工龄) × 月平均工资; 不满 6M 算半月; ≥6M<1Y 算 1M; 工资上限 = 当地社平 3 倍; 上限工资对应工龄上限 12 年 |
| 第48条 | 违法解除赔偿金 | 员工要求继续履行 → 继续履行; 不要求或不能履行 → 2N 赔偿金 (按 47 条计算然后 ×2) |
| 第50条 | 离职手续 + 工资结算 | 解除时一次性付清 + 15 日内办转移 (档案 / 社保) |
| 第82条 | 未签合同二倍工资 | 用工满 1 个月不满 1 年未签 → 每月支付 2 倍工资; 1 年仍未签 → 视为已订无固定期限合同 (第14条第3款); 2 倍工资差额诉讼时效 1 年 (按月起算) |
| 第87条 | 违法解除赔偿金条款 | 与第48条相同, 2 倍经济补偿 |
| 第91条 | 招用未解除员工的连带责任 | 给原单位造成损失 → 连带赔偿责任 |

## Termination Decision Tree

```
员工要离职?
├── 协商解除 → 第36条 → 单位提出 → 经济补偿; 员工提出 → 无补偿
├── 员工辞职 → 第37条 → 提前30日 → 无补偿
└── 员工被迫辞职 → 第38条 → 立即解除 → 经济补偿 + 可能赔偿金

单位要解雇?
├── 严重违纪 / 试用不合格 / 严重失职 / 兼职严重影响 / 欺诈 / 刑责 → 第39条 → 无补偿无代通知
├── 医疗期满 / 不胜任 / 客观情况重大变化 → 第40条 → 提前30日 OR 代通知金 + 经济补偿
├── 经济性裁员 → 第41条 → 程序+优先留用 + 经济补偿
└── 想解雇但属于第42条保护对象? → 不能用 40/41; 仍可用 39
违法解除? → 第48条 → 员工选: 继续履行 OR 2N 赔偿金
```

## High-Frequency Trap Map (employer side)

| Trap | Penalty | Mitigation |
|---|---|---|
| 用工后超过 1 个月仍未签书面合同 | 第82条 2 倍工资 | 入职日同步签合同; 留存签收回执 |
| 试用期不当延长 / 重复试用 | 试用期工资差额 + 视为正式 | 试用期一次为限; 不超第19条上限 |
| 规章制度未经民主程序 / 未公示 | 不能作为解除依据 (司法解释一第50条) | 职代会讨论 + 公示 + 员工签收 |
| 调岗未经协商 / 不合理调岗 | 视为变相解除 → 员工可被迫辞职 + 经济补偿 | 调岗前书面协商 + 给出合理理由 + 待遇不降 + 调岗合理性证据 |
| 第40条 "不胜任" 直接解除 | 程序违法 | 必须先培训或调岗 → 仍不胜任 → 才能解除 |
| 工会未通知 / 未答复 | 程序瑕疵 | 解除前 5 日书面通知工会; 留存送达证据 |
| 经济补偿计算基数错算 | 差额 + 2 倍工资风险 | 按"前 12 个月平均应得工资"; 不只是基本工资 |
| 三期 / 工伤 / 医疗期员工被解雇 | 违法解除 → 2N 赔偿金 + 继续履行风险 | 第42条 hard ban; 等待保护期满 |
| 离职后未结清工资 | 行政罚款 + 加付 50%-100% (《工资支付暂行规定》第18条) | 离职当日一次结清 |

## Critical Verbatim Provisions (to quote in reports)

When citing these, copy the Chinese text exactly — never paraphrase.

### 第14条第3款 (auto-conversion to open-ended)
"用人单位自用工之日起满一年不与劳动者订立书面劳动合同的，视为用人单位与劳动者已订立无固定期限劳动合同。"

### 第38条 (constructive dismissal grounds)
"用人单位有下列情形之一的，劳动者可以解除劳动合同：（一）未按照劳动合同约定提供劳动保护或者劳动条件的；（二）未及时足额支付劳动报酬的；（三）未依法为劳动者缴纳社会保险费的；（四）用人单位的规章制度违反法律、法规的规定，损害劳动者权益的；（五）因本法第二十六条第一款规定的情形致使劳动合同无效的；（六）法律、行政法规规定劳动者可以解除劳动合同的其他情形。"

### 第47条 (economic compensation calculation)
"经济补偿按劳动者在本单位工作的年限，每满一年支付一个月工资的标准向劳动者支付。六个月以上不满一年的，按一年计算；不满六个月的，向劳动者支付半个月工资的经济补偿。劳动者月工资高于用人单位所在直辖市、设区的市级人民政府公布的本地区上年度职工月平均工资三倍的，向其支付经济补偿的标准按职工月平均工资三倍的数额支付，向其支付经济补偿的年限最高不超过十二年。本条所称月工资是指劳动者在劳动合同解除或者终止前十二个月的平均工资。"

### 第87条 (illegal-termination penalty)
"用人单位违反本法规定解除或者终止劳动合同的，应当依照本法第四十七条规定的经济补偿标准的二倍向劳动者支付赔偿金。"
