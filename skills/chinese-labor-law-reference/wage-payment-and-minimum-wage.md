# Wage Payment and Minimum Wage — Practitioner Reference

> Statutes referenced:
> - 《工资支付暂行规定》 (劳部发 [1994] 489 号)
> - 《对〈工资支付暂行规定〉有关问题的补充规定》 (劳部发 [1995] 226 号)
> - 《最低工资规定》 (劳动和社会保障部第21号令, 2004-03-01 施行)
> - 《江苏省工资支付条例》 (江苏省人大常委会, 2005-01-01 施行, 2010 修正)
> - 《关于工资总额组成的规定》 (国家统计局第1号令, 1990) — defines what counts as 工资
> - 《国务院关于调整工资总额组成的通知》 — periodic clarifications

## What Counts as 工资 (Wage Composition)

国家统计局第1号令 第4条: 工资总额由以下 6 部分组成:
1. 计时工资
2. 计件工资
3. 奖金
4. 津贴和补贴 (包括 high-temperature subsidy / shift allowance / 工龄津贴 / etc.)
5. 加班加点工资
6. 特殊情况下支付的工资 (病假 / 事假 / 探亲假 / 婚假 / 丧假 / 产假 / 工伤 / 计划生育假 等期间的支付)

**Excluded from 工资**:
- 社保单位部分 (employer-paid social insurance)
- 公积金单位部分
- 福利费 (集体福利)
- 劳动保护用品
- 一次性 employee benefits not tied to labor (e.g., 中秋 fruit basket)
- 经济补偿 / 赔偿金 (these are NOT wages — separate accounting)

**Why this matters**: 加班费基数 / 经济补偿基数 / 病假工资基数 / 生育津贴基数 都按 工资 算. 单位想压低基数 → 把奖金 / 津贴 划入"福利" — 但 仲裁 / 法院 按 国家统计局 1990 号令 实质审查, 单位的"福利"分类不能对抗 法定 工资认定.

## Wage Payment Rules

工资支付暂行规定:

| Rule | Article | Practitioner note |
|---|---|---|
| 必须以 货币形式 支付 | 第5条 | 不能用 实物 / 有价证券 抵 |
| 必须 按月 支付 (至少) | 第7条 | 月薪员工 月发; 计件 季度结算+月预付 也可 |
| 必须直接 支付员工本人 | 第6条 | 委托他人代领 需员工书面授权 |
| 必须按时 (工资支付日) 支付 | 第7条 | 推迟 ≥1 个工资支付周期 → 算 拖欠 |
| 必须 提供 工资清单 | 第6条 | 单位需保存 ≥2 年 (建议 ≥3 年) |
| 解除 / 终止 劳动合同 时 一次性结清 | 第9条 | 含 当月 应得 + 加班费 + 未休年假 + 其他应付项 |

## Statutory Wage Reductions (合法扣款 4 类)

工资支付暂行规定第15条: 单位**不得克扣**员工工资, **除以下情形**:
1. 个人所得税
2. 法律 / 行政法规规定 由 单位代扣 (社保 / 公积金 / 法院执行 等)
3. 法院判决 / 裁决要求代扣的 抚养费 / 赡养费
4. 其他 法律法规 规定 可代扣

**因员工原因造成的损失 赔偿**: 工资支付暂行规定第16条 — 可从工资中扣除, 但**每月扣除部分不得超过 当月工资 20%**, 且 扣除后 剩余工资 不得低于 当地最低工资.

**违反**: 任意克扣 → 行政处罚 + 加付 50%-100% 赔偿金 (第18条).

## Withheld-Wage Penalties (拖欠工资)

| Trigger | Statute | Penalty |
|---|---|---|
| 单位克扣 / 无故拖欠 | 工资支付暂行规定第18条 | 责令支付 + 加付 25% 经济补偿; 经书面通知仍不支付 → 加付 50%-100% 赔偿金 |
| 离职时 未及时结清 | 工资支付暂行规定第9条 + 第18条 | 同上 |
| 拒不支付 数额较大 | 刑法第276条之一 (拒不支付劳动报酬罪) | 3 年以下 / 3-7 年 + 罚金 (经政府部门责令支付仍不支付) |
| 员工 因拖欠工资 被迫离职 | 劳动合同法第38条 + 第46条 | 经济补偿 N |

## Suzhou / Jiangsu Minimum Wage (current at 2024)

> **CONFIRM LATEST RATE** before issuing any report — Jiangsu adjusts annually around year-end.

Jiangsu uses 4-tier classification by city:

| Tier | Cities | Monthly minimum (full-time) | Hourly minimum (part-time) |
|---|---|---|---|
| 一类 | 南京 / 无锡 / 常州 / 苏州 (city core) | ¥2,490 | ¥24/hour |
| 二类 | 苏州 (<your-region> / 常熟 / 张家港 / etc.) / 镇江 / 南通 / 扬州 / 泰州 | ¥2,260 | ¥22/hour |
| 三类 | 徐州 / 连云港 / 淮安 / 盐城 / 宿迁 | ¥2,030 | ¥20/hour |
| 四类 | (recently 撤销; 最新 江苏 仅有 3 档) | — | — |

**your-region (<your-region>)** specific: <本区> belongs to **二类** in current scheme — ¥2,260/月 (full-time) / ¥22/小时 (part-time). **Verify at 苏州市人社局 official site.**

**What 最低工资 includes / excludes** (《最低工资规定》第12条):
- **Includes**: 标准 base + 部分 津贴
- **Excludes**: 加班费; 中班 / 夜班 / 高温 / 低温 / 井下 / 有毒有害 等特殊环境津贴; 法律法规规定的 福利待遇 (社保 / 公积金 / 餐补 / 交通补贴)

实务: 苏州 倾向 严格分离 — 加班费 + 高温津贴 + 夜班津贴 都不能算入 最低工资 是否达标 的计算.

## High-Temperature Subsidy (高温津贴) — Jiangsu

> 关注: 操作员厂区 高温车间 + 化学接触 — 高温津贴 漏付 是仲裁高频项.

Jiangsu: 6 月 1 日 - 9 月 30 日 适用. 若 单位 安排 室外 露天作业 OR 工作场所 不能采取 有效措施 将室温降到 33°C 以下:

| Type | Monthly subsidy |
|---|---|
| 露天作业人员 | ¥300/月 |
| 室内 33°C 以上工作人员 | ¥200/月 |

**Compliance check (印染 染整 industry)**:
- 染色车间 (高卷 / 溢流 / 汽流缸) 通常 ≥35°C — 必须支付 ¥200/月
- 整理车间 (定型机 / 拉幅) 通常 ≥35°C — 必须支付 ¥200/月
- 验布 / 包装 / 仓库 通常 < 33°C (如有空调) — 可不支付; 留 温度记录 备查

**漏付**: 仲裁追溯 1 年; 单位负 举证责任 (高温记录 / 空调记录).

## Garnishment and Attachment (法院执行 / 强制扣划)

法院执行 工资 时, 应保留 员工本人及所抚养家属 的 必要生活费. 民诉法 + 最高院 执行规定: 一般保留 ≥ 当地最低工资 标准. 单位有 协助义务, 不能 拒绝 配合 (民诉法第248条).

## High-Frequency Pitfalls (employer-side, 印染 industry)

| Pitfall | Frequency | Consequence | Mitigation |
|---|---|---|---|
| 高温津贴 漏付 / 选择性发 | High | 1 年时效内仲裁 + 加付 25% | 6/1 起 名单全员 ¥200-300 |
| 加班费 按 最低工资 算基数 | High | 差额 + 25% 经济补偿 | 按 应得工资 (合同 + 实际) 算 |
| 夜班 / 中班 津贴 算入 最低工资 是否达标 | Medium | 视为 工资 < 最低工资 → 行政处罚 + 差额 | 拆分核算 |
| 计件工资 < 最低工资 (按 合理 工时折算) | Medium | 单位 补足 + 罚款 | 工时定额 必须 经科学测算 + 经 工会 / 职代会 协商 |
| 罚款 ≥ 月工资 20% OR 罚后低于最低工资 | High | 仲裁追回 + 单位过错 | 罚款 ≤ 月工资 20% AND 留薪 ≥ 最低工资 |
| 离职 当月 工资 拖到 次月 发 | High | 仲裁支持 + 25% 经济补偿 | 离职日 一次性结清 |
| 工资清单 不发 / 不留底 | Medium | 仲裁 时 举证不能 → 推定 员工主张 | 月发 工资条 (邮箱 / 微信 / 纸质); 留底 ≥3 年 |
| 用 现金发工资 / 微信红包 (规避 个税 / 社保) | High | 个税 / 社保 风险; 仲裁 时 双方对账 困难 | 银行代发 + 标 "工资" |
