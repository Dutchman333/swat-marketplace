# Civil Code — Property Book (物权编)

> Statute: 《中华人民共和国民法典》第二编 物权 (第205-462条), 2021-01-01 施行
> Companion: 《最高人民法院关于适用〈中华人民共和国民法典〉有关担保制度的解释》(法释 [2020] 28 号, 2021-01-01 施行)

## Three-Tier Structure

| Tier | Coverage | Key articles |
|---|---|---|
| **物权 总则** | 物权 设立 / 变更 / 转让 / 消灭; 公示 (登记 / 交付); 物权请求权 | 第208-239条 |
| **所有权** | 国家 / 集体 / 私人 所有权; 业主的建筑物区分所有权; 相邻关系; 共有; 善意取得 | 第240-322条 |
| **用益物权** | 土地承包经营权; 建设用地使用权; 宅基地使用权; **居住权 (新增)**; 地役权 | 第323-385条 |
| **担保物权** | 抵押权; 质权 (动产 / 权利); 留置权 | 第386-457条 |
| **占有** | 占有 状态 / 善意占有 / 恶意占有 / 返还请求权 | 第458-462条 |

## Property Right Effects (物权 效力)

第208条: 不动产物权 设立 / 变更 / 转让 / 消灭, 应当 依法 **登记**; 动产物权 设立 / 转让, 应当 依法 **交付** (除非法律另有规定).

**未登记 / 未交付 的 法律效果**:
- 不动产 未登记 → 物权 不发生 变动效力 (但 当事人间 合同 仍有效, 第215条)
- 动产 未交付 → 物权 不发生 变动效力 (但 当事人间 合同 仍有效)

**例外**: 船舶 / 航空器 / 机动车 等 特殊动产 → 登记 对抗 善意第三人 (登记不是 设立要件, 但是 对抗要件; 第225条).

## 居住权 (Right of Residence) — NEW in 民法典

第366-371条: 自然人 对 他人 住宅 享有 占有 + 使用 的 用益物权, 满足 生活居住 需要.

**关键**:
- 必须 **书面 合同** + **登记** 设立 (第366-368条)
- 无偿 (除非 当事人 另有约定)
- 不得 转让 / 继承
- 设立 居住权 的 住宅 不得 出租 (除非 当事人 另有约定)
- 居住权 期限 / 终止 见 第370条
- 也可以 通过 遗嘱 设立 居住权 (第371条) — **重要 接班人场景**

**操作员 实务**: 父亲 (董事长) 可通过 遗嘱 + 居住权 安排 母亲 / 其他亲属 终身居住权, 同时 房屋 所有权 由 操作员 / 子女 继承; 既保护 居住 又实现 财产传承.

## 担保物权 (Security Interests)

3 类: 抵押 / 质押 / 留置.

### 抵押 (Mortgage) — 第394-425条

**抵押财产 范围** (第395条) — 7 大类:
1. 建筑物 + 其他土地附着物
2. 建设用地使用权
3. 海域使用权
4. 生产设备 / 原材料 / 半成品 / 产品
5. 正在建造的建筑物 / 船舶 / 航空器
6. 交通运输工具
7. 法律 / 行政法规 未禁止抵押的 其他财产

**抵押人** 可 **同一财产 抵押多家债权人** (第414条) — 顺位规则:
1. 已登记 → 按 登记时间 先后 顺位
2. 已登记 优先于 未登记
3. 都未登记 → 按 债权 比例 受偿

**抵押权 实现** (第410条):
- 协议 — 折价 / 拍卖 / 变卖
- 起诉 → 申请执行
- 直接 申请 法院 拍卖 / 变卖 (新增 简化 路径)

**最高额抵押** (第420-424条): 一段 期间内 连续发生 的 债权, 在 最高 限额 内 担保.

### 质押 (Pledge)

| 类型 | 标的 | 设立 |
|---|---|---|
| **动产 质押** | 动产 (e.g. 设备 / 货物) | 出质人 + 质权人 签 书面合同 + **交付** 质物 (第427条) |
| **权利 质押** | 汇票 / 本票 / 支票 / 债券 / 存款单 / 仓单 / 提单 / 基金份额 / 股权 / 知识产权 / 应收账款 等 7 类 (第440条) | 书面 + 交付 OR 登记 (依 标的 类型) |

**股权质押**: 必须 在 工商登记机关 (市场监管) 办理 出质登记 (第443条).

**应收账款质押**: 必须 在 中登网 (中国人民银行 征信中心) 办理 出质登记 (第445条).

### 留置 (Lien)

第447-457条. 债务人 不履行 到期债务 → 债权人 可以 留置 已合法占有 的 债务人动产, 以该 动产 优先受偿.

**适用 范围**: 主要 限于 因 保管 / 运输 / 加工承揽 / 加工修理 等关系 占有 的 动产.

**企业之间** 可以 留置 与债权 不属于 同一法律关系 的 动产 (第448条 — 企业间 留置 范围 较宽).

## 共有 (Co-Ownership) — 第297-310条

2 类:
- **按份共有** (各按 份额 享有所有权) — 处分 / 重大修缮 → 占份额 2/3 以上 同意 (第301条)
- **共同共有** (不分份额, 平等享有) — 处分 / 重大修缮 → 全体 一致 同意

**夫妻共同共有** (第1062-1063条) — 见 marriage-and-family-book.

## 善意取得 (Bona Fide Acquisition) — 第311条

无处分权人 将 不动产 / 动产 转让 给 受让人, 受让人 满足 三要件 → 取得 该不动产 / 动产 所有权:
1. 受让人 受让该 不动产 / 动产 时 是 **善意**
2. 以 **合理价格** 转让
3. 不动产 已 **登记** OR 动产 已 **交付**

**例外**: 抢夺 / 盗窃 / 遗失 等 非自愿丧失 占有 的 动产 → 原所有权人 2 年内 仍可追回 (第311条第3款; 但 拍卖 / 公开市场 / 经营该类商品的 经营者 处购得 → 须支付 价款).

## High-Frequency Use Cases for the Operator (Personal-Side Property)

### Case A: 个人 房产 婚前 / 婚后 区分
- 婚前 一方 全款购买 + 登记 该方名下 → 个人婚前财产 (第1063条)
- 婚后 共同还贷 (婚前 按揭) → 房产 仍 个人; 但 婚后 还贷 部分 + 增值 → 离婚时 补偿 配偶
- 婚后 一方 父母 全款 给 一方购买 + 登记 该方 → 视为 父母 对该方 个人赠与 → 个人财产 (民法典 + 婚姻家庭编 司法解释一第29条)
- 婚后 双方 共同购买 → 共同 财产 (除非 约定)

### Case B: 担保 保证 不要轻易签
- 担保物权 + 保证 (合同编) — 担保 债务人 不还 → 担保人 兜底
- 个人 担保 → 全部 个人财产 (含 婚后共同 — 除非 约定 个人) 都可被 执行
- 操作员 已知 "担保: 无" — 维持 这个 状态 是 重要的 风险隔离

### Case C: 厂里 设备 抵押 融资
- 印染 设备 (高卷缸 / 汽流缸 / 溢流) → 第395条 第4类 生产设备 → 可抵押
- 必须 在 市场监管局 (动产抵押) 登记 — 否则 不能 对抗 善意第三人
- 注意 抵押 顺位 — 同一台设备 多家 抵押 的 风险

### Case D: 居住权 用于 继承筹划
- 父亲 可通过 遗嘱 设定 居住权: 房产 所有权 给 操作员 / 孙女; 终身 居住权 给 母亲 / 其他长辈
- 居住权 必须 登记 才设立 → 遗嘱 + 死后 配合 登记 程序
