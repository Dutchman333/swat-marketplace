# Civil Code — Personality Rights and Personal Information (人格权编)

> Statute: 《中华人民共和国民法典》第四编 人格权 (第989-1039条), 2021-01-01 施行 — 第一次 在 民法典 中 独立成编, 立法新意明显
> Companions:
> - 《中华人民共和国个人信息保护法》(PIPL, 2021-11-01 施行) — 与人格权编 第六章 衔接
> - 《中华人民共和国妇女权益保障法》(2022 修订, 2023-01-01 施行) — 性骚扰防治 衔接
> - 《最高人民法院关于审理利用信息网络侵害人身权益民事纠纷案件适用法律若干问题的规定》

## Eight Personality Rights

| Right | Articles | Notes |
|---|---|---|
| 生命权 | 第1002条 | 不可让与, 不可剥夺 |
| 身体权 | 第1003条 | 身体完整 + 行动自由 |
| 健康权 | 第1004条 | 身心健康 |
| 姓名权 | 第1012-1017条 | 姓名 决定 / 使用 / 变更 / 许可他人使用 |
| 肖像权 | 第1018-1023条 | 不得 利用信息技术 伪造 (新增, 针对 AI deepfake) |
| 名誉权 | 第1024-1028条 | 公民 + 法人 + 非法人组织 都享有; 评论 + 公正使用 + 适度使用 |
| 荣誉权 | 第1031条 | 政府 / 单位 / 组织授予的 荣誉称号 |
| 隐私权 + 个人信息保护 | 第1032-1039条 | 二者 区分 + 衔接 |

## Critical New Article — Sexual Harassment (第1010条)

第1010条 (verbatim, 不能改写):
"违背他人意愿, 以言语、文字、图像、肢体行为等方式对他人实施性骚扰的, 受害人有权依法请求行为人承担民事责任.
机关、企业、学校等单位应当采取合理的预防、受理投诉、调查处置等措施, 防止和制止利用职权、从属关系等实施性骚扰."

**第二款 关键** = **单位 法定 防治义务** (机关 / 企业 / 学校 等). 不履行 → 单位 可承担 侵权责任 + 行政责任.

**衔接**: 妇女权益保障法 (2022 修订) 第25条 — 进一步细化 单位防治义务: 制定规章制度 + 公布投诉渠道 + 设立 处置机制 + 教育培训 + 保护 投诉人.

**操作员 厂里** (女员工 比例 高) — 必备 性骚扰防治制度 + 投诉渠道 + 处置流程. 漏 → 单位 受 行政处罚 + 民事 连带责任 风险.

## 隐私权 vs 个人信息 — Distinction

| Concept | Articles | Definition |
|---|---|---|
| 隐私 | 第1032条第2款 | 自然人 私人生活安宁 + 不愿为他人知晓 的 私密空间 / 私密活动 / 私密信息 |
| 个人信息 | 第1034条 | 以电子或其他方式记录的 能够单独 OR 与其他信息结合 识别 特定自然人 的 各种信息: 自然人 姓名 / 出生日期 / 身份证件号码 / 生物识别信息 / 住址 / 电话号码 / 电子邮箱 / 健康信息 / 行踪信息 等 |

**重叠**: 个人信息 中 的 私密信息 → 优先 适用 隐私权 规定.

## 隐私权 — 6 类禁止行为 (第1033条)

除 法律 另有规定 OR 权利人 明确同意 外, 任何 组织 / 个人 不得:
1. 以电话 / 短信 / 即时通讯工具 / 电子邮件 / 传单 等方式 侵扰 他人 私人生活安宁
2. 进入 / 拍摄 / 窥视 他人 住宅 / 宾馆房间 等 私密空间
3. 拍摄 / 窥视 / 窃听 / 公开 他人 私密活动
4. 拍摄 / 窥视 他人 身体 私密部位
5. 处理 他人 私密信息
6. 以其他方式 侵害 他人 隐私权

## 个人信息 处理 — 8 项原则 (第1035条 + PIPL)

第1035条 处理 个人信息 应当 遵循:
1. 合法 / 正当 / 必要 原则
2. 不得 过度 处理
3. 满足 5 条件:
   (1) 征得 该自然人 OR 其监护人 同意 (法律 / 行政法规 另有规定 除外)
   (2) 公开 处理信息的 规则
   (3) 明示 处理信息 的 目的 / 方式 / 范围
   (4) 不违反 法律 / 行政法规 的规定 + 双方约定
   (5) 与 PIPL 等 法律 衔接

**处理** = 收集 / 存储 / 使用 / 加工 / 传输 / 提供 / 公开 等.

## 个人信息 主体的 6 项权利 (第1037条)

自然人 可以 依法 向 信息处理者:
1. **查阅 / 复制** 其个人信息
2. 发现信息 有错误 → **请求 更正**
3. 发现 处理 信息 违反法律 / 行政法规 / 双方约定 → **请求 删除**

## 信息处理者 法定免责事由 (第1036条)

3 类:
1. 在该自然人 OR 其监护人同意范围内 合理实施
2. 合理处理 该自然人 自行公开 OR 其他已经合法公开 的信息 — 但该自然人 明确拒绝 OR 处理该信息 侵害 其重大利益 的 除外
3. 为维护 公共利益 OR 该自然人合法权益, 合理实施 的 其他行为

## High-Frequency Use Cases for the Operator

### Case A: 厂里 性骚扰 投诉 → 单位 防治义务
- 第1010条第2款 + 妇女权益保障法第25条 — 单位 必须 已建 防治制度 (规章 + 投诉 + 处置) — 否则 民事 连带责任 风险
- 操作员 应 立即 制定 / 修订 公司 性骚扰 防治制度, 经 民主程序 + 公示, 设立 投诉 渠道, 培训 HR + 主管层

### Case B: 厂里 员工 体检数据 / 工资 / 银行账户 / 监控视频 — 个人信息
- 第1034条 列举的 健康信息 / 工资 → 属于 个人信息
- 必须 (a) 取得 同意; (b) 公开规则; (c) 明示目的; (d) 限定范围
- HR 系统 / 考勤系统 / 监控视频 — 都 触发 PIPL + 民法典 人格权编 双重义务

### Case C: 操作员 个人 / 家人 网络 名誉权 受损
- 第1024条 — 任何组织 / 个人 不得 以 侮辱 / 诽谤 等方式侵害 他人名誉权
- 救济: 停止侵害 + 删除 + 消除影响 + 恢复名誉 + 赔礼道歉 + 赔偿 (含 精神损害)
- 时效 3 年 自 知道 / 应当知道之日 起算

### Case D: AI deepfake / 换脸 视频 — 操作员 / 家人 肖像被滥用
- 第1019条第1款 + 第1023条 (新增) — 不得 利用信息技术 手段 伪造 等方式 侵害 他人肖像权
- 特别 针对 AI 生成 / 深度伪造 — 救济同上

### Case E: 客户 客户名单 / 商业秘密 + 个人信息 双重保护
- 客户 联系人 + 联系方式 → PIPL 个人信息
- 客户 商业 信息 → 反不正当竞争法 商业秘密
- 离职员工 拷走 / 泄露 → 双重违法
- 见 chinese-corporate-law-reference 商业秘密 + PIPL 章节
