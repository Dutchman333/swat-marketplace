# Civil Code — Marriage and Family Book (婚姻家庭编)

> Statute: 《中华人民共和国民法典》第五编 婚姻家庭 (第1040-1118条), 2021-01-01 施行
> Companion: 《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释 (一)》(法释 [2020] 22 号, 2021-01-01 施行)
> 历史: 民法典施行后, 《婚姻法》(1980, 2001 修正) + 《收养法》(1991, 1998 修正) 全部废止, 内容 整合 进 民法典 第五编

## Marriage Formation (结婚)

**结婚条件** (第1046-1051条):
- 男 ≥22, 女 ≥20 (第1047条)
- 完全自愿 (不能强迫 / 干涉)
- 一夫一妻
- 不能 直系血亲 + 三代以内旁系血亲 (第1048条)

**结婚程序** (第1049条): 应当 亲自 到 婚姻登记机关 申请 — 取得 结婚证 → 确立 夫妻关系.

**婚姻 无效** (第1051条) — 4 类: 重婚 / 直系或三代内旁系血亲 / 未到法定婚龄 / 不能与他人结婚的 (no longer includes 患不应当结婚的疾病 — 民法典已删除).

**婚姻 可撤销** (第1052-1053条) — 2 类:
- 因 胁迫 结婚 → 受胁迫方 撤销, 1 年 除斥期间 自 胁迫终止之日 起算
- 一方 隐瞒 重大疾病 → 另一方 撤销, 1 年 除斥期间 自 知道 / 应当知道 撤销事由之日 起算

## Spousal Property (夫妻财产)

### 共同财产 (Default Regime, 第1062条)

夫妻 在 婚姻关系 存续期间 所得的 下列财产 — **共同所有**, 平等处分:
1. 工资 / 奖金 / 劳务报酬
2. **生产 / 经营 / 投资 收益** ← **重要 (操作员 succession-track)**
3. 知识产权 收益
4. **继承 / 受赠 的 财产** (除非 第1063条第3项 — 遗嘱 / 赠与合同 中 确定 只归 夫 OR 妻 一方)
5. **其他 应当归共同所有 的 财产**

**关键**: 婚姻期间 当事人 的 工资 + 投资收益 + 公司 / 集团 分红 + 受赠资产 — **默认共同**, 除非 婚前 / 财产协议 特别 约定 OR 赠与合同 / 遗嘱 明确 个人.

### 个人财产 (第1063条) — 5 类
1. 一方 婚前 财产
2. 一方 因 受到人身损害 获得的 赔偿 / 补偿
3. **遗嘱 / 赠与合同 中 确定 只归一方 的 财产** ← **核心 (succession 工具)**
4. 一方 专用 的 生活用品
5. 其他 应当归 一方所有 的 财产

### 夫妻 财产 约定 (Prenup / Postnup, 第1065条)

可在 婚前 / 婚后 任何时点 书面约定:
- 婚前 + 婚后 财产 各自所有
- 共同所有
- 部分各自 部分共同

**对内 + 对外 效力**: 约定 对 双方 有效. 夫妻 一方 与 第三人 进行 民事活动, 第三人 知道 该约定 的 → 该约定 对 第三人 也有约束力 (第1065条第3款).

**实务 (Suzhou)**: 夫妻 财产 约定 公证 + 由 律师 起草 + 必要时 第三人 (e.g. 银行 / 投资标的方) 知悉 — 才能 完整 对抗 第三人.

## Spousal Debt (夫妻共同债务) — 第1064条

**3 种 共同债务**:
1. 夫妻双方 共同 签名 OR 一方 事后追认 等共同意思表示
2. 婚姻关系 存续期间 一方以 个人名义 为 **家庭日常生活需要** 所负的债务
3. 婚姻关系 存续期间 一方以 个人名义 超出 家庭日常生活需要 所负的债务, 债权人 能证明 该债务 用于 夫妻共同生活 / 共同生产经营 OR 基于 夫妻双方 共同意思表示 的

**家庭日常生活需要** (司法解释一第26条) = 维持 一般家庭日常生活 所必需 (柴米油盐 / 房贷 / 教育 / 医疗 等 — 与 家庭收入水平 相关; 一般 ¥5-10 万 以下 的 个人借款 可推定为家庭 日常)

**其他 (高额 / 投资 / 经营) — 推定 个人** → 债权人 必须 举证 证明 用于 夫妻共同生活 / 经营 OR 双方共同意思表示.

**对操作员的 实务影响**: 操作员 接班人 / 总经理助理 — 个人 可能 为 公司经营 借款 / 担保. 若 借款 / 担保 用于 公司经营 收益 进入 婚后共同 → 配偶 可能 共同承担.

## Divorce (离婚)

**2 路径**:

### 1. Registered Divorce (协议离婚) — 第1076-1078条
- 双方自愿 + 对 子女抚养 + 财产 + 债务 处理 达成一致
- **30 日 离婚冷静期** (第1077条) — 自 婚姻登记机关 收到 离婚登记申请之日 起 30 日, 任何一方 可撤回; 30 日届满后 30 日内, 双方 应当 亲自 到 婚姻登记机关 申请 发给 离婚证; 未申请 → 视为 撤回
- 共 60 日 流程

### 2. Litigated Divorce (诉讼离婚) — 第1079-1080条
- 一方 起诉, 调解无效 + 感情确已破裂 → 准予离婚
- **法定 准予离婚 5 类情形** (第1079条):
  (1) 重婚 OR 与他人同居
  (2) 实施 家庭暴力 OR 虐待 / 遗弃 家庭成员
  (3) 有 赌博 / 吸毒 等 恶习 屡教不改
  (4) 因 感情不和 分居满 2 年
  (5) 其他 导致 夫妻感情破裂 的情形
  + 失踪宣告满 2 年, 配偶 可以 起诉离婚 (第1079条第5款)
- 第一次 起诉 法院 不准离婚 + 判决后 又分居满 1 年, 一方 再次 起诉离婚 → 应准予 (第1079条第5款) — **重要 实务规则**

## Property Division at Divorce (离婚财产分割)

**协议优先, 协议不成 → 法院 判决** (第1087条):
- 由 法院 根据 财产 具体情况, 按照 照顾 子女 / 女方 / 无过错方 权益的原则 判决
- 实务: 50:50 是 default, 但 子女 / 女方 / 无过错方 倾向 有偏好

**离婚 损害赔偿** (第1091条) — 5 种 情形 无过错方 可请求:
1. 重婚
2. 与他人同居
3. 实施 家庭暴力
4. 虐待 / 遗弃 家庭成员
5. **有 其他 重大过错** (兜底)

**离婚后 发现 一方 隐藏 / 转移 / 变卖 / 毁损 / 挥霍 共同财产 OR 伪造 共同债务** → 离婚后 3 年内 (从 知道 / 应当知道之日 起算) 可起诉 重新分割; 该方 可少分 OR 不分 (第1092条).

## Children — Custody, Support (抚养)

**2 周岁以下** 子女 → 默认 母亲 直接抚养 (第1084条第3款); 母亲 有 不宜抚养情形 例外
**2-8 岁** 子女 → 父母双方 协议; 协议不成 → 法院 按 最有利于 未成年子女 原则
**8 周岁以上** → 应当 尊重 其 真实意愿 (第1084条第3款)

**抚养费** (第1085条):
- 标准: 一般 月总收入 20-30%; 多个孩子 ≤50%; 无固定收入 → 当年总收入 OR 同行业平均收入 的 20-30%
- 期限: 至 子女 18 岁 OR 完成 高中阶段教育 (尚在 高等教育 不属强制)
- 未完成 高中 但 ≥16 + 以自己劳动收入为主要生活来源 → 父母 可中止给付
