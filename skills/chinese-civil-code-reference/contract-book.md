## Structure (3 sub-编)

1. **通则** (第463-594条) — 一般规则: 订立 / 效力 / 履行 / 保全 / 变更转让 / 终止 / 违约责任
2. **典型合同** (第595-978条) — 19 类
3. **准合同** (第979-988条) — 无因管理 + 不当得利

## 准合同 (Quasi-Contract)

- **无因管理** (第979-984条): 没有 法定 / 约定 义务, 为 避免 他人利益受损 而 管理 他人事务. 可 请求 必要费用 + 损失补偿
- **不当得利** (第985-988条): 一方 没有 法律根据 取得 不当利益, 受损失方 可 请求 返还

## Contract Formation (订立)

**要约 + 承诺** (第471-484条):
- 要约 = 希望 与他人 订立 合同 的 意思表示
- 承诺 = 受要约人 同意 要约 的 意思表示
- 承诺 到达 要约人 → 合同 成立

**3 种 例外**:
- **悬赏广告** (第499条) → 完成 行为 即 取得 报酬请求权
- **实践合同** (赠与 / 自然人之间借款 / 保管 等) → 交付 标的物 才成立
- **要式合同** (建设工程 等 法定 书面) → 不签 书面 → 不成立

**格式条款** (第496-498条):
- 提供方 必须 提请对方 注意 + 按要求 说明 (尤其 免责 / 限责 / 排除对方权利 条款)
- 不公平 / 不合理 → 不发生效力
- 有 2 种以上 解释 → 作 不利于 提供方 的 解释 (第498条)

## Contract Performance (履行)

**全面履行 + 诚信履行 + 经济合理 / 不损害公共利益** (第509-510条).

**先履行抗辩权** (第526条): 应 先履行 一方 未履行 → 后履行方 可 拒绝 履行

**同时履行抗辩权** (第525条): 双方 互负 同时履行 义务 → 一方未履行 / 不符合约定 → 另一方 可 拒绝 履行

**不安抗辩权** (第527-528条): 应 先履行 一方 有 确切证据 证明对方 经营严重恶化 / 转移财产 / 抽逃资金 / 丧失商业信誉 / 其他 丧失或可能丧失履行能力 情形 → 可中止 履行 + 要求 提供 担保

## Termination (合同 终止) — 第557-566条

**终止 7 种情形** (第557条):
1. 债务 已经 履行
2. 债务 相互抵销
3. 债务人 依法将标的物 提存
4. 债权人 免除债务
5. 债权债务 同归于一人
6. 法律规定 / 当事人约定 终止 的其他情形
7. (合同) **解除**

**法定解除** (第563条) — 5 类:
1. 不可抗力 致 不能实现合同目的
2. 履行期限届满前, 一方明确表示 / 以行为表明 不履行 主要债务
3. 一方 迟延履行 主要债务, 经催告 在 合理期限内 仍未履行
4. 一方 迟延履行债务 OR 其他违约行为 致 不能实现 合同目的
5. 法律 规定的 其他情形

**约定解除** (第562条): 当事人 约定 解除 条件 → 条件 成就 → 享有解除权

**解除权 行使期限** (第564条): 法律 / 约定 没有期限 → 自 解除权人 知道 / 应当知道 解除 事由 之日 起 1 年内; 经对方催告后 → 合理期限内.

## Liability for Breach (违约责任) — 第577-594条

**承担方式**:
- 继续履行
- 采取 补救措施
- 赔偿 损失

**违约金** (第585条): 当事人可约定; 约定 低于 实际损失 → 法院 / 仲裁机构 可调整 提高; 约定 过分高于 实际损失 (一般 30% 以上) → 可调整 降低

**预期利益** (第584条): 损失赔偿额 = 实际损失 + 合同履行后 可获得 的 利益; 但 不得超过 违约方 订立合同 时 预见或应当预见 的 损失

## High-Frequency Use Cases for the Operator (Industry Side)

### Case A: 印染 加工承揽合同 (操作员 厂里) — 客户拖欠加工费
- 适用 第770-787条 承揽合同
- 注意 工作成果 验收时间 → 视为 默认 验收 后, 不能再主张 质量问题 (除非 隐蔽瑕疵)
- 拖欠 加工费 → 留置权 (第780条) — 可以 留置 客户 已交付 但未付款 的 货物 → 优先受偿
- 时效: 3 年, 起算 应付款日

### Case B: 染料 / 助剂 采购合同 (操作员 厂里) — 供应商 货物 不合格
- 买卖合同 第595-647条
- 质量异议期: 合理期间内 (第621条); 约定 期间 优先
- 6 个月 法定 异议期 (隐蔽瑕疵, 第621条第2款)
- 退货 / 换货 / 修理 / 减少价款 / 损害赔偿

### Case C: 厂房 / 设备 租赁
- 租赁合同 第703-734条
- 期限 上限 20 年 (超过 20 年 部分 无效, 第705条)
- 不破租赁 (买卖 不影响租赁, 第725条) — 厂房 出售 后 新业主 仍受 租赁约束
- 优先购买权 (第726条) — 业主 出售 厂房 → 同等条件下 承租人 优先购买

### Case D: 民间借贷 (操作员 个人 / 朋友 借款)
- 借款合同 第667-680条
- 利率上限: LPR (一年期 LPR) 4 倍 — 司法保护 上限 (民间借贷 司法解释)
- 自然人之间 借款 → **实践合同** — 必须 实际 交付 借款 才成立 (第679条)
- 没有约定 利息 → 视为 无息 (自然人之间; 第680条)
- 借条 / 借款合同 + 转账记录 + 催款记录 — 三件套必备

### Case E: 民间借贷 + 保证
- 保证合同 第681-702条
- 没有约定 保证方式 → **一般保证** (第686条 — 司法解释 修正了 旧法 默认 连带 的规定)
- 一般保证 → 主合同 纠纷 未经审判 / 仲裁 + 强制执行 不能履行前, 保证人 可拒绝 承担保证责任 (先诉抗辩权)
- 连带保证 → 债务到期 不履行, 债权人 可 直接要求 保证人 / 债务人 承担
