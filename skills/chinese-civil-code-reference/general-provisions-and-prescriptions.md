# Civil Code — General Provisions and Prescriptions (总则编)

> Statute: 《中华人民共和国民法典》第一编 总则 (第1-204条), 2021-01-01 施行
> Companion: 《最高人民法院关于适用〈中华人民共和国民法典〉总则编的解释》(法释 [2022] 6 号, 2022-03-01 施行)

## Civil Subjects (民事主体)

| Subject | Definition | Capacity |
|---|---|---|
| 自然人 | 出生 → 死亡 (第13条) | 民事权利能力一律平等 (第14条); 行为能力分 完全 / 限制 / 无 三类 (第17-22条) |
| 法人 | 营利 (公司) / 非营利 (事业 / 社团 / 基金会 / 社会服务) / 特别 (机关 / 农村集体 / 城镇农村合作经济 / 基层群众性自治) (第76-101条) | 法定代表人 行为 = 法人 行为 (第61条) |
| 非法人组织 | 个人独资 / 合伙 / 不具有法人资格的专业服务机构 (第102-108条) | 出资人 / 设立人 对债务承担 无限责任 |

**民事行为能力 三类 (自然人)**:
- 完全 (≥18 OR ≥16且以自己劳动收入为主要生活来源)
- 限制 (≥8 + <18, OR 不能完全辨认自己行为的成年人) — 行为 需 法定代理人 同意/追认; 但 与年龄 / 智力 / 精神状况 相适应的 行为有效
- 无 (<8 OR 不能辨认自己行为的成年人) — 行为 由 法定代理人代理

## Civil Legal Acts (民事法律行为) — Validity

第143条 **有效要件**:
1. 行为人 具有 相应的 民事行为能力
2. 意思表示 真实
3. 不违反 法律 / 行政法规 的 强制性规定; 不违背 公序良俗

**Invalid (无效)** — 第144 / 146 / 153 / 154 / 155条:
- 无民事行为能力人 实施
- 通谋虚伪 (双方 虚假意思表示)
- 违反 法律 / 行政法规 强制性规定 (除非 该规定 不导致 民事法律行为 无效)
- 违背 公序良俗
- 恶意串通 损害 他人合法权益

**Voidable (可撤销)** — 第147-152条:
- 重大误解 (90 日除斥期间 知道 / 应当知道之日 起算; 第152条)
- 显失公平 (1 年 除斥期间)
- 欺诈 (1 年 除斥期间, 知道 / 应当知道之日 起算; 5 年 最长 自 民事法律行为 发生之日 起算)
- 胁迫 (1 年, 自 胁迫行为 终止之日 起算)
- 第三人 欺诈 (相对人 知道 / 应当知道时, 受欺诈方 可请求撤销; 第149条)

**部分有效 / 部分无效**: 民事法律行为 部分 无效, 不影响 其他部分效力 → 其他部分 仍有效 (第156条).

## Agency (代理)

3 类: 委托代理 (第165-172条) / 法定代理 (第163条) / 指定代理.

**表见代理** (第172条): 行为人 没有 代理权 / 超越 代理权 / 代理权 终止后 实施 代理行为, 相对人 有理由相信 行为人 有代理权 → 代理行为 有效.

**自我代理 / 双方代理 禁止** (第168条): 代理人 不得 以 被代理人名义 与自己 民事法律行为, 也不得 同时代理 双方 (除非 被代理人 同意 / 追认).

## Civil Liability — General Rules (第176-187条)

**承担 民事责任 方式** (第179条) — 11 类:
1. 停止侵害
2. 排除妨碍
3. 消除危险
4. 返还财产
5. 恢复原状
6. 修理 / 重作 / 更换
7. 继续履行
8. 赔偿损失
9. 支付违约金
10. 消除影响 / 恢复名誉
11. 赔礼道歉

**惩罚性赔偿** (第179条第2款): 法律规定的, 适用 (主要在 产品责任 / 知识产权 / 食品安全 / 消费者权益保护 等 特别法).

## Prescriptions (诉讼时效) — 第188-199条

| Type | Length | Start | Source |
|---|---|---|---|
| **普通诉讼时效** | **3 年** | 知道 / 应当知道 权利受损 + 义务人 (第188条第2款) | 第188条第1款 |
| **最长保护期** (绝对时效) | **20 年** | 权利 被侵害之日 (不可中止 / 中断) | 第188条第2款 |
| 国际货物买卖 / 技术进出口 | 4 年 (CISG) | 知道权利受损时 | CISG 第8条; 中国 已加入 |
| 普通时效 中止事由 | 时效 暂停; 事由 消除 6 个月内 满 | 不可抗力 / 无民事行为能力 等 6 类 | 第194条 |
| 普通时效 中断事由 | 重新计算 | 一方主张权利 / 一方同意履行 / 提起诉讼或申请仲裁 / 与提起诉讼或申请仲裁 等同效力的情形 | 第195条 |
| 不适用 时效 (4 类) | 不受 时效 限制 | — | 第196条 |

**第196条 不适用 时效 4 类**:
1. 请求 停止侵害 / 排除妨碍 / 消除危险
2. 不动产 物权 + 登记的 动产 物权 的 权利人 请求 返还财产
3. 请求 支付 抚养费 / 赡养费 / 扶养费
4. 依法 不适用 诉讼时效 的 其他 请求权

## High-Frequency Use Cases for the Operator

### Case A: 厂里 设备买卖合同 客户拖欠货款 (典型 3 年时效)
- 合同到期日 → 知道 客户违约 → 时效 起算
- 时效 期间 持续 主张 (微信 / 邮件 / 律师函) → 时效 中断 → 重新 计算
- 超过 3 年 起诉 → 客户 可援引 时效 抗辩 → 法院 不支持 (但 仅当 客户 主动 抗辩)
- 操作员 实务: 每 18 月 至少 1 次 书面 主张 (留 送达证据)

### Case B: 个人 借款 / 民间借贷
- 借款合同 约定 还款期 → 还款期 届满 起算
- 借款合同 未约定 还款期 → 出借人 主张 + 合理期限 → 起算

### Case C: 离婚 财产 重大误解 / 欺诈 撤销
- 重大误解: 90 日 除斥期间 (短)
- 欺诈: 1 年 知道 / 应当知道 + 5 年 最长 (民事法律行为 发生之日 起算)
- 实务: 离婚后 1 年内 发现 对方 隐藏 / 转移 共同财产 → 民法典 第1092条 + 司法解释一 → 重新分割 (3 年 时效 自 发现之日 起算)

### Case D: 工厂 化学品 / 高温 / 高危 侵权 (人身损害)
- 普通时效 3 年, 起算 受害人 知道 / 应当知道 损害 + 侵权人
- 但 职业病 / 慢性损害 — 起算 通常 自 诊断书 出具日
- 最长 20 年 — 化学品 慢性 致癌 等 长期 暴露 案件 须特别注意
