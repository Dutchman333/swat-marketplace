# Civil Code — Inheritance Book (继承编)

> Statute: 《中华人民共和国民法典》第六编 继承 (第1119-1163条), 2021-01-01 施行
> Companion: 《最高人民法院关于适用〈中华人民共和国民法典〉继承编的解释 (一)》(法释 [2020] 23 号, 2021-01-01 施行)
> 历史: 民法典施行后, 《继承法》(1985) 全部废止 — 内容 整合, 部分条款 修订 (新增 打印 / 录像 遗嘱; 新增 遗产管理人; 取消 公证 遗嘱 优先效力)

## When Does Inheritance Begin (继承开始)

第1121条: **继承 从 被继承人 死亡时 开始**.

**死亡** = 自然死亡 OR 宣告死亡 (第13 / 47-49条).

## What's Inheritable (遗产范围)

第1122条: **遗产** = 自然人 死亡时 遗留的 个人 合法财产.

**包括**: 现金 / 银行存款 / 房产 / 车 / 公司股权 / 股票 / 基金 / 知识产权 财产权 / 债权 / 古董 / 收藏品 / 网络虚拟财产 (e.g. 加密货币 — 视情形, 实务 仍有 争议) ...

**不包括** (人身性 / 不可分割):
- 人身 性质 (如 抚养费 请求权 / 退休金 待遇)
- 与 个人 不可分离的 权利 (如 名誉权 / 肖像权 — 但 损害赔偿请求权 可继承, 第994条)

## Statutory Inheritance (法定继承)

### 顺序 (第1127条) — 2 顺位

**第一顺位**: 配偶 / 子女 / 父母

**第二顺位**: 兄弟姐妹 / 祖父母 / 外祖父母

继承开始, 第一顺位继承人 继承; 没有 第一顺位 继承人 OR 都 放弃 / 丧失 → 第二顺位 继承.

**子女 包括**: 婚生 / 非婚生 / 养 / 有扶养关系 的 继子女
**父母 包括**: 生父母 / 养父母 / 有扶养关系 的 继父母
**兄弟姐妹**: 同父母 / 同父异母 / 同母异父 / 养 / 有扶养关系 的 继兄弟姐妹

### 份额 (第1130条)

**Default 平均**: 同一顺位 继承人 继承遗产 的 份额, 一般应当 均等.

**例外** (法院 OR 协议 可调整):
- 对 被继承人 尽 主要扶养义务 OR 与其共同生活 → 可多分
- 有扶养能力 + 有扶养条件 但 不尽扶养义务 → 应不分 OR 少分
- 缺乏劳动能力 + 没有生活来源 → 应予照顾

### 代位继承 (Successio Loci) — 第1128条

被继承人 子女 先于 被继承人 死亡的, 由该 子女的 直系晚辈血亲 (孙 / 曾孙 等) 代位 继承.

**民法典 新增**: 被继承人 兄弟姐妹 先于 被继承人 死亡的 → 由 该 兄弟姐妹的 子女 代位 继承 (第1128条第2款) — **重要新增**, 旧法 没有此条.

### 转继承 (Successio Mediata) — 第1152条

继承开始 后, 继承人 在 遗产分割前 死亡, 没有放弃继承 的 → 该继承人 应继 份额 转给 该继承人 的继承人.

## Testamentary Succession (遗嘱继承) — 第1133-1144条

### 遗嘱 6 类 (第1134-1139条)

| 类型 | Article | 形式 要求 |
|---|---|---|
| **公证遗嘱** | 第1139条 | 公证机构 办理 |
| **自书遗嘱** | 第1134条 | 由 遗嘱人 亲笔书写, 签名, 注明 年/月/日 |
| **代书遗嘱** | 第1135条 | 应当有 2 个以上 见证人 在场见证, 由其中一人 代书; 由 遗嘱人 / 代书人 / 其他见证人 签名, 注明 年/月/日 |
| **打印遗嘱** ★ | 第1136条 | 应当有 2 个以上 见证人 在场见证; 由 遗嘱人 + 见证人 在 每一页 签名, 注明 年/月/日 |
| **录音录像遗嘱** ★ | 第1137条 | 应当有 2 个以上 见证人 在场见证; 遗嘱人 + 见证人 应当 在 录音 / 录像 中 记录其 姓名 OR 肖像 + 年/月/日 |
| **口头遗嘱** | 第1138条 | 仅在 危急情况 下 适用; 应当有 2 个以上 见证人 在场见证. 危急情况 消除后, 遗嘱人 能够 用书面 / 录音录像 形式立遗嘱 → 口头遗嘱 失效 |

★ 民法典 新增类型 (旧法 没有 打印 + 录音录像 单独规定; 公证遗嘱 优先效力 也被取消)

### 遗嘱 关键 修改 (民法典 vs 旧法)

| Item | 旧法 | 民法典 |
|---|---|---|
| 公证遗嘱 优先 | 优先于 其他遗嘱 | **取消** — 多份遗嘱 内容相抵触 → 以 **最后** 遗嘱 为准 (第1142条第3款) |
| 打印 遗嘱 | 不明确 | **新增 第1136条** |
| 录音录像 遗嘱 | 仅 录音 (无 录像) | **录音 + 录像 都可** (第1137条) |
| 见证人 资格 | (基本同) | 第1140条 — 不能担任 见证人 的 3 类: 无 / 限制 行为能力人; 继承人 / 受遗赠人; 与继承人 / 受遗赠人 有利害关系的人 |

### 遗嘱 撤回 / 变更 / 失效 (第1142条)

遗嘱人 可撤回 / 变更. 立遗嘱后, 遗嘱人 实施 与遗嘱内容 相反的 民事法律行为 (e.g. 卖了 房 后 又立遗嘱 把房给 A) → 视为 对 遗嘱相关内容的 撤回.

立有 数份遗嘱 + 内容相抵触 → 以 **最后的** 遗嘱 为准.

## Legacy + Support Agreement (遗赠 + 遗赠扶养协议)

### 遗赠 (第1133条第3款 + 第1124条)
- 遗赠 = 遗嘱 把财产 给 法定继承人 之外的 组织 / 个人
- 受遗赠人 应当 在 知道 受遗赠后 60 日内 作出 接受 OR 放弃 表示; 到期没有表示 → 视为 **放弃** (第1124条第2款; 注意 与 法定继承 默认接受 不同)

### 遗赠扶养协议 (第1158条)
- 自然人 与 继承人以外的 组织 / 个人 签订 遗赠扶养协议
- 该 组织 / 个人 承担 自然人 生养死葬 的 义务 → 自然人 死亡时 该 组织 / 个人 享有 受遗赠 的 权利
- **效力 顺位**: 遗赠扶养协议 > 遗嘱 (含 遗赠) > 法定继承 (第1123条)

## Estate Administrator (遗产管理人) — NEW

第1145-1149条 新增:

**产生**: 
- 遗嘱 指定 → 按遗嘱执行人 担任
- 没有 遗嘱执行人 → 继承人 推选 + 没有推选 → 全体继承人 共同担任
- 没有继承人 / 继承人都放弃 → 由 被继承人 生前住所地的 民政部门 OR 村委会担任

**职责** (第1147条) — 6 项: 清理 + 编遗产清单 + 报告 + 妥善保管 + 处理债权债务 + 按 遗嘱 / 法律 分割 + 实施 与管理遗产有关的 其他必要行为.

**操作员 实务**: 父亲 立遗嘱 时 应同时 指定 遗嘱执行人 (可以是 操作员 OR 律师 OR 银行 信托). 若 集团 资产 复杂 → 推荐 律所 + 信托 公司 联合担任.

## Forced Heirship — 必留份 (第1141条)

遗嘱 应当 为 缺乏劳动能力 又 没有生活来源 的 继承人 保留 必要的 遗产 份额 — **必留份**.

**遗嘱 完全剥夺 该类继承人 继承权** → 该部分遗嘱 无效 → 必留份 仍归 该继承人.

## Renunciation / Loss of Inheritance Rights

### 接受 / 放弃 (第1124条)
- 继承开始后, 继承人 放弃继承 → 应当 在 遗产处理前 以 **书面** 形式 作出 表示; 没有表示 → 视为 **接受** (与 受遗赠 相反)

### 丧失 继承权 (第1125条) — 5 类
1. 故意杀害 被继承人
2. 为争夺 遗产 杀害 其他继承人
3. 遗弃 被继承人 OR 虐待 被继承人 情节严重
4. 伪造 / 篡改 / 隐匿 / 销毁 遗嘱 情节严重
5. 以 欺诈 / 胁迫 手段 迫使 OR 妨碍 被继承人 设立 / 变更 / 撤回 遗嘱 情节严重

第3-5 项 — 确有 悔改表现 + 被继承人 表示宽恕 OR 事后 在 遗嘱中 将其列为 继承人 → 该继承人 不丧失 继承权.
