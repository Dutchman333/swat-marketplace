# Chinese Civil Code Reference

## Use When

- The brief involves any private-law dispute (合同 / 物权 / 侵权 / 婚姻 / 继承 / 人格权 / 个人信息)
- The brief involves a contract issue (formation, performance, modification, termination, breach, damages)
- The brief involves real estate, mortgage, lien, or other property security
- The brief involves marriage, divorce, joint property, prenuptial agreement, child custody, child support, alimony, or domestic violence
- The brief involves inheritance, will, intestate succession, support agreement, or estate distribution
- The brief involves tort liability (personal injury, product liability, traffic accident, environmental damage, medical malpractice)
- The brief involves personality rights (life / health / name / portrait / reputation / privacy / personal information)
- The brief involves prescription periods (民事诉讼时效) or limitations of actions

## Reading Rules

- 民法典 全文 retrievable at flk.npc.gov.cn (《中华人民共和国民法典》, 2020-05-28 通过, 2021-01-01 施行).
- 民法典 施行后, 之前的 9 部 separate laws 全部废止 (《婚姻法》 / 《继承法》 / 《民法通则》 / 《收养法》 / 《担保法》 / 《合同法》 / 《物权法》 / 《侵权责任法》 / 《民法总则》). 引用 时 一律 用 民法典, 不能 引用 已废止的旧法.
- 配套 司法解释: 民法典 实施后, 最高院 陆续 发布 配套 司法解释 (婚姻家庭编 / 继承编 / 合同编 等). 引用时 必须 同时 标 民法典 条文 + 司法解释 条文.
- 旧法 案件 (2020-12-31 前 行为 / 事实) → 适用 旧法 + 旧 司法解释 (法不溯及既往原则; 民法典 时间效力规定 第1条 — 但 涉及 民事权利 持续性变更 / 三种除外情形 → 可适用 民法典). 时间效力规则 详见 《最高人民法院关于适用〈中华人民共和国民法典〉时间效力的若干规定》.
- 诉讼时效 通常 **3 年** (第188条第1款); 特殊 1 年 (国际货物买卖 / 技术进出口 — 但 国际货物 仍 适用 4 年, 见 联合国国际货物销售合同公约). 最长保护期 20 年 (第188条第2款), 自 权利 受到损害之日 起算, 不可中止 / 中断 / 延长.
- 时效 的 **起算点** 是 知道 OR 应当知道 权利受损 + 义务人 双重要件 (第188条第2款).
- 个人 / 家庭 重点书 (Scenario 2): **婚姻家庭编 + 继承编 + 物权编** (婚姻状态 + 子女 / 父母 + 房产 / 投资 / 担保 等关系按 personal-company-profile 配置)
- 公司 / 业务 重点书 (Scenario 1): **合同编 + 侵权责任编 + 物权编 (担保)** (B2B 合同 / 客户纠纷 / 高危作业 + 担保)
