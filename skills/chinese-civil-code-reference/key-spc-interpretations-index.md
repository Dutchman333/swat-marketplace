# Civil Code Companion — Key SPC Interpretations Index

> Status: 民法典 施行后 (2021-01-01), 最高人民法院 已发布 多个 配套 司法解释. 引用 时 必须 同时 标 民法典 条文 + 司法解释 条文.
> Verify latest text at the SPC official site (court.gov.cn) or pkulaw.com — interpretations are amended periodically.

## Top-Level Time-Effect Rule

| 司法解释 | 编号 | 施行日期 | 范围 |
|---|---|---|---|
| 《最高人民法院关于适用〈中华人民共和国民法典〉时间效力的若干规定》 | 法释 [2020] 15 号 | 2021-01-01 | 关键: 民法典 实施 前 的 法律事实 引起的 民事纠纷 + 时效 / 期间 / 程序 适用规则; 民事行为 是否 适用 民法典 vs 旧法 |

**核心规则**: 民事案件 法律事实 发生在 民法典 施行后 → 适用 民法典. 法律事实 发生在 民法典 施行前 → 适用 当时的 法律 / 司法解释; 但 几种例外 → 适用 民法典 (持续性 + 民事 权利 / 法律行为 + 民法典 利于 当事人 / 公序良俗 等).

## How to Cite — Format Convention

**Combined citation**:
```
《民法典》第X条第Y款 + 《最高人民法院关于适用〈中华人民共和国民法典〉Z编的解释 (X)》第N条
```

**Example**:
"操作员 父亲 通过 遗嘱 + 配套 个人专属赠与协议 给 操作员 公司股权 — 适用《民法典》第1063条第3项 (遗嘱 / 赠与合同 中确定只归一方的财产 → 个人财产) + 《最高人民法院关于适用〈中华人民共和国民法典〉婚姻家庭编的解释 (一)》第29条 (赠与协议 / 遗嘱 内容 明确 + 仅 给一方 → 另一方 不享有共有 / 期待权)."
