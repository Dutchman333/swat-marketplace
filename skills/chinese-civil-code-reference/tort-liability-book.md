# Civil Code — Tort Liability Book (侵权责任编)

> Statute: 《中华人民共和国民法典》第七编 侵权责任 (第1164-1258条), 2021-01-01 施行
> Companions:
> - 《最高人民法院关于审理人身损害赔偿案件适用法律若干问题的解释》(2003 制定, 2020 修正)
> - 《最高人民法院关于审理因生态环境损害产生的损害赔偿案件适用法律若干问题的解释》
> - 《最高人民法院关于审理道路交通事故损害赔偿案件适用法律若干问题的解释》
> 历史: 民法典施行后, 《侵权责任法》(2009) 全部废止 — 内容 整合 进 民法典 第七编

## Three Liability Standards

| Standard | Articles | When |
|---|---|---|
| **过错责任** | 第1165条第1款 | Default — 行为人 因过错 侵害 他人 民事权益 → 承担侵权责任 |
| **过错推定** | 第1165条第2款 | 法律规定 行为人 有过错 推定; 行为人 不能证明 自己 没有过错 → 承担责任 (e.g. 物件致损 - 部分类型) |
| **无过错** | 第1166条 | 法律规定 不论 是否 有过错 → 承担责任 (e.g. 产品责任 / 高度危险 / 环境污染 / 饲养动物 部分情形) |

## Damages (赔偿范围)

### 财产损失 (第1184条)
- 按 损失 发生时 的 市场价格 OR 其他合理方式 计算

### 人身损害 (第1179条)
- 医疗费 + 护理费 + 交通费 + 营养费 + 住院伙食补助费 等 因 治疗 + 康复 支出 的 合理费用 + 因 误工 减少的 收入
- 致残 → + 辅助器具费 + 残疾赔偿金
- 死亡 → + 丧葬费 + 死亡赔偿金

### 精神损害 (第1183条)
- 侵害 自然人 人身权益 造成 严重精神损害 → 被侵权人 可请求 精神损害赔偿
- 因 故意 OR 重大过失 侵害 自然人 具有 人身意义 的 特定物 → 也可请求

### 惩罚性赔偿 (第1185 / 1207 / 1232条)
- **侵害 知识产权** 故意 + 情节严重 → 第1185条
- **产品责任** 明知 缺陷 仍生产 / 销售 / 提供服务 致他人 死亡 / 健康严重损害 → 第1207条
- **生态环境** 故意 违反法律 → 第1232条
- 其他 法律规定的 (e.g. 食安法 / 消费者权益保护法 1+10 倍 等)

## Joint Liability (共同侵权 / 连带责任)

**共同侵权** (第1168条) — 二人以上 共同实施 侵权行为 → **连带** 责任

**教唆 / 帮助** (第1169条) — 教唆 / 帮助 他人 实施侵权 → 与侵权人 连带

**共同危险** (第1170条) — 二人以上 实施 危及 他人人身 / 财产安全 的 行为 + 实际侵害行为 由 其中一人 / 数人 造成 + 不能确定 具体 侵权人 → 行为人 承担 连带 责任

**多个侵权 同一损害** (第1171-1172条):
- 二人以上 分别实施 侵权行为 + 造成 同一损害 + 每个人的 侵权行为 都足以 造成 全部损害 → 连带
- 二人以上 分别实施 侵权行为 + 造成 同一损害 + 能够确定 责任大小 → 各自承担相应责任; 难以确定 → 平均承担

## Special Liability Categories

### 1. 产品责任 (第1202-1207条)
- **生产者** — 因 产品 存在 缺陷 造成 他人损害 → **无过错** 责任
- **销售者** — 销售者 过错 → 销售者 责任
- 销售者 不能指明 缺陷产品 的 生产者 OR 供货者 → 销售者 承担 责任
- 缺陷 → 销售前已存在 → 生产者 / 销售者 内部追偿
- **惩罚性赔偿** (第1207条): 明知缺陷 + 仍生产 / 销售 + 致 他人死亡 / 健康严重损害 → 被侵权人 可请求 相应 惩罚性赔偿

### 2. 机动车 交通事故 (第1208-1217条)
- 适用 道路交通安全法 + 民法典
- 强制保险 (交强险) 先赔 + 商业保险 + 机动车 一方 责任
- 机动车 一方 责任比例 — 看 交警 责任认定书 + 法院 综合判断

### 3. 医疗损害 (第1218-1228条)
- **过错** 责任 — 医疗机构 + 医务人员 有过错 → 医疗机构 责任
- 推定过错 (第1222条) — 3 种情形:
  (1) 违反 法律 / 行政法规 / 规章 等 关于 诊疗规范 的规定
  (2) 隐匿 OR 拒绝 提供 与纠纷有关 病历资料
  (3) 遗失 / 伪造 / 篡改 / 违法 销毁 病历资料

### 4. 环境污染 + 生态破坏 (第1229-1235条)
- **无过错** 责任 — 因 污染环境 / 破坏生态 造成 他人损害 → 侵权人 应承担 侵权责任
- 举证责任 倒置 — 由 污染者 承担 不存在因果关系 的举证责任 (民诉法司法解释配合)
- 惩罚性赔偿 (第1232条)

### 5. 高度危险作业 (第1236-1244条)
- 民用核设施 / 民用航空器 / 高度危险物 (易燃 / 易爆 / 剧毒 / 放射性 / 病原体 / 强腐蚀 等) / 高空 / 高压 / 地下挖掘 / 高速轨道运输工具 等
- **无过错** 责任 — 但 被侵权人 故意 OR 不可抗力 造成 → 不承担 OR 减轻
- **印染 工厂 触发**: 化学品 (剧毒 / 强腐蚀 / 易燃) 储存 + 高温 整理 + 高压 染色 — 部分 操作 落入 高度危险 范畴, 民事侵权 标准 高于一般

### 6. 饲养动物 (第1245-1251条)
- 饲养 动物 致 他人损害 → **无过错** 责任 (一般)
- 受害人 故意 OR 重大过失 → 减轻 OR 不承担
- 违反 管理规定 + 未对 动物 采取 安全措施 → **无过错** 而且 受害人 重大过失 也不能 减轻

### 7. 物件 致损 (第1252-1258条)
- 建筑物 / 构筑物 / 其他设施 + 搁置物 / 悬挂物 倒塌 / 塌陷 / 脱落 / 坠落 → 所有人 / 管理人 / 使用人 / 施工人 (部分情形 推定过错)
- 高空抛物 (第1254条) — 禁止 + 物业 安保 义务 + 难以确定 具体侵权人时 由 可能加害的 建筑物使用人 给予 补偿 (实务 高发 + 高 social impact)

### 8. 网络侵权 (第1194-1197条)
- 网络用户 + 网络服务提供者 利用网络 侵害 他人 民事权益 → 责任
- 通知 - 删除 规则 (notice-and-takedown): 权利人 通知 → 网络服务提供者 应及时 转送 + 必要措施; 未及时 → 与 该网络用户 承担 连带责任 (扩大 损失部分)
- 反通知规则 — 被通知方 可提交 反通知 + 不构成侵权 声明 → 网络服务提供者 应及时 转送

## Causes for Reduction / Exemption

| Cause | Article |
|---|---|
| 受害人 故意 | 第1174条 — 不承担 |
| 受害人 过错 | 第1173条 — 减轻 |
| 第三人 原因 | 第1175条 — 行为人 不承担 (一般规则); 但 部分 特殊侵权 第三人原因 仍由 行为人 + 第三人 共同担责, 见 各特殊章节 |
| 不可抗力 | 第180条 + 第1166条 例外 — 一般 不承担; 特殊 (高度危险 / 环境污染 等) 仍可能 担责 |
| 正当防卫 | 第181条 — 不承担; 超过必要限度 → 适当承担 |
| 紧急避险 | 第182条 — 不承担; 超过 必要限度 → 适当承担 |
| 自助行为 | 第1177条 (民法典新增) — 严格条件下 自助 + 没有给 他人造成 损害 → 不承担 |

## Compensation Standards (赔偿标准 — 城乡 同标 改革)

历史: 旧法 城镇 / 农村 居民 死亡赔偿金 / 残疾赔偿金 标准 不同 — 城高 农低.

民法典 施行 + 配套 司法解释:
- **2021-12-31 后** 受理 + 受害人 是 农村 居民 → 仍可主张 城镇 标准 (《最高人民法院关于授权 高级人民法院 在辖区内 开展 人身损害 城乡赔偿 标准统一 试点 工作的通知》 + 各省 落实)
- 江苏 已 全省 统一 — 不再 区分 城乡

**死亡赔偿金 / 残疾赔偿金 计算** (江苏 现行 - 须 verify 最新数据):
- 死亡赔偿金 = 上一年度 江苏省 城镇居民人均可支配收入 × 20 年 (60-75 周岁 × 减少 1 年/年; 75 周岁 以上 × 5 年)
- 残疾赔偿金 = 同上 × 伤残系数

## High-Frequency Use Cases for the Operator (Industry Side)

### Case A: 工厂 化学品 / 高温 致 第三方 (访客 / 周边 居民) 损害
- 第1236条 高度危险作业 — 无过错责任
- + 第1229条 污染环境 — 无过错 + 举证责任倒置
- 厂区 应有 (a) 警示 (b) 隔离 (c) 应急 (d) 监测 (e) 保险
- 苏州 / 江苏 印染行业 — 环保 高压 + 民事侵权 高发 — 操作员 应特别 注意

### Case B: 设备 故障 致 客户 (B2B) 损害
- 产品责任 (第1202条) — 无过错
- 销售合同 + 侵权 竞合 — 客户 可选 (一般 选 侵权 — 不受 合同 约定 限责 限制)
- 防御: 出厂前 严格 QA + 留存 检验记录; 商业 责任 险 (产品 责任险)

### Case C: 厂里 员工 因 化学品 接触 / 高温 中暑 致死
- 工伤 (优先 — 工伤 + 工伤保险) — 见 chinese-labor-law-reference
- + 民事 侵权 (在 工伤 之外, 部分情形 可主张) — 视 职业病 / 第三人 原因 / 单位过错 程度
- 操作员 实务: 工伤保险 全员 + 商业保险 双重 + 安全生产 SOP + 应急

### Case D: 工厂 物件 致损 (吊顶 脱落 / 设备 倒塌)
- 第1252-1253条 — 建筑物 / 设备 致损 → 所有人 / 管理人 责任 (推定过错; 不能证明 没过错 → 担责)
- 防御: 设备 / 厂房 定期 维护 + 检查记录 留存

### Case E: 操作员 个人 / 家人 — 道路交通事故 + 物业 高空抛物 + 网络侵权
- 道路交通: 交强险 优先 + 责任比例 → 法院 综合
- 高空抛物 (城市) — 物业 安保 + 业主 共同 补偿 风险 (第1254条)
- 网络侵权: 通知 - 删除 走平台 (微博 / 抖音 / 小红书 投诉 渠道); 严重 → 民事 起诉 + 公安
