## 7 Types of Unfair Competition Acts (反不正当竞争法 第6-12条)

| Type | Article | Examples |
|---|---|---|
| 1. 仿冒 / 混淆 | 第6条 | 擅自 使用 他人 有 一定影响的 商品名称 / 包装 / 装潢 / 企业名称 / 简称 / 字号 / 域名 / 网站名称 / 网页 等 |
| 2. 商业 贿赂 | 第7条 | 财物 / 其他手段 贿赂 交易对方 工作人员 / 受 委托 的 单位 OR 个人 |
| 3. 虚假 宣传 | 第8条 | 商品 性能 / 功能 / 质量 / 销售 状况 / 用户评价 / 曾 获 荣誉 等 虚假 OR 引人误解 的 商业宣传 |
| 4. 商业 秘密 侵犯 | 第9条 | 见下文 — 4 类 行为 |
| 5. 不正当 有奖 销售 | 第10条 | 信息 不明确 / 欺诈 / 抽奖 最高奖金 > 5 万 |
| 6. 商业 诋毁 | 第11条 | 编造 / 传播 虚假信息 OR 误导性 信息, 损害竞争对手 商誉 |
| 7. 平台 经济 新型 不正当竞争 | 第12条 (2017 新增) | 利用技术 手段 + 通过 影响 用户 选择 OR 其他方式 妨碍 / 破坏 其他 经营者 合法 提供的 网络产品 / 服务 正常运行: 强制 跳转 / 误导 / 欺骗 / 强迫 用户 修改 / 关闭 / 卸载 / 妨碍 其他 经营者 网络产品 OR 服务 正常运行 |

## Trade Secret — Three-Element Test (商业秘密 三要件)

第9条 (verbatim):
"本法 所称 的 商业秘密, 是指 不为 公众 所知悉, 具有 商业 价值, 并经 权利人 采取 相应 保密措施 的 技术信息 / 经营信息 等 商业信息."

| Element | 中文 | 实务 关键 |
|---|---|---|
| 1. 秘密性 | 不为 公众 所知悉 | 不能 在 公开 渠道 (期刊 / 专利 / 网络 / 行业会议) 直接 获取; 反向 工程 难度 |
| 2. 价值性 | 具有 商业 价值 | 现实 / 潜在 价值; 对 持有人 形成 竞争优势 |
| 3. 保密措施 | 相应 保密措施 | 标识 (机密 / 秘密) + 物理 / 电子 隔离 + 访问 控制 + NDA + 培训 + 离职 处理 |

**司法解释 第3-7条** 详细 列举 7 类 保密措施 形式.

## 4 Categories of Trade Secret Infringement (第9条第1款)

经营者 不得 实施 下列 侵犯 商业秘密 的 行为:
1. 以 盗窃 / 贿赂 / 欺诈 / 胁迫 / 电子侵入 / 其他 不正当 手段 获取 权利人 商业秘密
2. 披露 / 使用 OR 允许他人 使用 以 上述 手段 获取的 权利人 商业秘密
3. 违反 保密义务 OR 违反 权利人 有关 保守 商业秘密 的 要求, 披露 / 使用 OR 允许他人 使用 其 所掌握 的 商业秘密
4. 教唆 / 引诱 / 帮助 他人 违反 保密义务 OR 违反 权利人 有关 保守 商业秘密 的 要求, 获取 / 披露 / 使用 OR 允许他人 使用 权利人 商业秘密

**第三人** (第9条第2款) 明知 / 应知 商业秘密 是 上述 不正当 手段 取得, 仍 获取 / 披露 / 使用 / 允许 他人 使用 → 视为 侵犯 商业秘密.

## Damages (第17条) — Loss + 利润 + 法定 + 惩罚性

**计算 顺序**:
1. 实际损失 (权利人 因侵权 受到的 损失)
2. 难以 计算 → 侵权人 因侵权 获得的 利润
3. 都难以 计算 → 法院 综合 判赔 (法定 ≤ 500 万)
4. **故意** 侵犯 + **情节严重** → 1-5 倍 **惩罚性赔偿** (第17条第3款 — 商业秘密 / 仿冒 等 都适用)

## Burden of Proof — 商业秘密 案件

第32条 (2019 修正 重要) — 举证 责任 部分 转移:
"权利人 提供 初步证据 证明 已对 所主张的 商业秘密 采取 保密措施, 且 合理 表明 商业秘密 被 侵犯, 涉嫌 侵权人 应当 证明 权利人 所主张 的 商业秘密 不属于 本法规定 的 商业秘密."

**实务 影响**: 权利人 (员工 离职 + 拷走 配方) 提交 (a) 保密措施 证据 (b) 合理 推断 侵权 → 涉嫌 侵权人 必须 反证 — 大幅 减轻 权利人 举证 难度.

## Non-Compete Agreement (劳动合同法 第23-24条) — 与 商业秘密 配套

非常 重要 — 详细 见 `chinese-labor-law-reference/labor-contract-law.md` 第22-24条.

**核心**:
- 期限 ≤ 2 年
- 限定 6 类人 (高级管理人员 / 高级技术人员 / 其他 知悉 商业秘密 人员)
- **必须 按月 支付 经济补偿** — 没有 支付 → 该 条款 不生效 (司法解释一第36条)
- 违反 → 员工 支付 违约金 + 停止 行为
- 月补偿 标准 — 有 约定 按约定; 没有 约定 → 不低于 离职前 12 月平均工资 30% (实务 普遍)

## High-Frequency Use Cases for the Operator (Industry Side)

### Case A: 染整 配方 / 工艺参数 — 商业秘密 保护
- 三要件 评估:
  - 秘密性: 配方 — 通常 满足 (染料 + 助剂 + 浴比 + 温度 / pH / 时间 曲线 — 不在 公开 渠道); 工艺参数 — 部分 满足 (公开 文献 + 操作员 调整)
  - 价值性: 满足 — 直接 影响 良率 / 成本 / 质量
  - 保密措施: 这是 操作员 必须 强化 的 — 制度 + 标识 + 访问控制 + NDA + 培训 + 离职处理
- 实务 SOP:
  (1) 配方库 加密 + 仅 ≤5 人 访问 (技术总监 / 染缸主管 / 厂长)
  (2) 配方 文档 / 系统 标 "机密 - 商业秘密"
  (3) 入职 NDA + 同业 / 服务期 (高薪 + 培训 投入 大 → 服务期; 普通 → NDA + 离职 同业 限制)
  (4) 离职 流程: 数据 / 配方 文档 收回 + 系统 权限 关闭 + 出具 离职 声明 (无 携带商业秘密)
  (5) 离职 同业限制 — 月补偿 + 限制 期限 (一般 1 年; ≤2 年)
  (6) 监控 + 跟踪 — 可疑 离职 (e.g. 跳槽 直接 竞争对手)

### Case B: 客户 名单 / 联系人 — 商业秘密 + 个人信息 双重保护
- 客户名单 — 满足 三要件 即 商业秘密 (满足 与否 看 编排 / 整理 / 维护 投入)
- 客户 个人信息 — PIPL 同时 适用
- 离职员工 拷走 / 转给 竞争对手 — 反不正当竞争法 第9条 + 民法典 + PIPL — 三 重叠

### Case C: 同行 仿冒 / 假冒 操作员 集团 商品 / 品牌
- 第6条 (有 一定影响 的 名称 / 包装 / 装潢) — 集团 / 子公司 名称 / 商标 / 包装
- 救济: 起诉 + 损害赔偿 + 临时禁令
- 配套: 商标 注册 + 包装 著作权 / 外观 专利

### Case D: 同行 商业 贿赂 / 商业诋毁
- 第7条 商业 贿赂 — 客户 采购 / 招投标 中 给 客户方 工作人员 财物 / 其他手段
- 第11条 商业 诋毁 — 同行 散布 操作员 集团 印染 / 染整 质量 不合格 / 环保 不达标 等 虚假信息
- 救济: 起诉 + 损害赔偿 + 行政举报 (市场监管局)

### Case E: 集团 内部 / 关联方 — 防御 不正当竞争 风险
- 集团 3 家公司 之间 业务 / 资源 流转 — 注意 不要 涉嫌 同行 不正当 (一般 关联 方 之间 不构成 不正当竞争, 但 涉及 客户 名单 / 商业秘密 仍 须 关注)
