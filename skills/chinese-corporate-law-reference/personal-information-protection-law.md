# Personal Information Protection Law (PIPL) — Practitioner Reference

> Statute: 《中华人民共和国个人信息保护法》(2021-08-20 通过, 2021-11-01 施行)
> Companions:
> - 《中华人民共和国数据安全法》(2021-09-01 施行) — see `data-security-law.md`
> - 《中华人民共和国网络安全法》(2017 施行)
> - 《信息安全技术 个人信息安全规范》(GB/T 35273-2020) — 推荐性国标 (实务 重要参考)
> - 《个人信息出境标准合同办法》(2023-06-01 施行) — 跨境 路径之一
> - 《数据出境安全评估办法》(2022-09-01 施行) — 跨境 路径之一
> - 《促进和规范数据跨境流动规定》(2024-03-22 施行) — 减负 + 自贸区 实务

## Scope and Definitions

### Personal Information (第4条)
"个人信息 是 以 电子 OR 其他方式 记录的 与已识别 OR 可识别的 自然人 有关的 各种信息, 不包括 匿名化 处理后 的 信息."

### Sensitive Personal Information (第28条) — 6 类
"敏感 个人信息 是 一旦 泄露 或者 非法使用, 容易 导致 自然人 的 人格尊严 受到侵害 OR 人身 / 财产 安全 受到危害 的 个人信息":
1. 生物识别 (人脸 / 指纹 / 声纹 / 虹膜 等)
2. 宗教 信仰
3. 特定身份
4. 医疗 健康
5. 金融 账户
6. 行踪 轨迹
7. 不满 14 周岁 未成年人 的 个人信息

**敏感 个人信息 处理 规则 加严** (第29-32条): 必须 单独 同意 + 处理目的 + 处理方式 + 范围 + 影响 全面告知; 处理 前 进行 影响评估.

## 7 Lawful Bases for Processing (第13条)

只有 满足 以下 之一, 才可 处理 个人信息:
1. **取得 个人 同意** — Default route, 知情 + 自愿 + 明确; 处理目的 / 方式 / 范围 / 期限 等告知后
2. 为订立 / 履行 个人 作为一方 当事人 的合同 所必需, OR 按照 依法制定的 劳动 规章 + 集体合同 实施 人力资源管理 所必需
3. 为履行 法定职责 OR 法定义务 所必需
4. 为应对 突发公共 卫生 事件, OR 紧急情况下 为保护 自然人 生命 健康 + 财产 安全 所必需
5. 为公共利益 实施 新闻报道 / 舆论监督 等 行为, 在 合理范围 内 处理
6. 依照 本法 规定 在 合理范围 内 处理 个人 自行公开 OR 其他已经合法公开 的 个人信息
7. 法律 / 行政法规 规定 的 其他情形

**Consent — 单独同意场景** (第14 / 25 / 26 / 29 / 39条): 涉及 (a) 敏感 个人信息; (b) 公开个人信息; (c) 共同处理 + 共同处理者; (d) 提供给 第三方; (e) 跨境 → 必须 **单独同意**, 不能 一揽子.

## Processor's Obligations (第50-58条)

| Obligation | Article |
|---|---|
| 制定 内部 管理制度 + 操作规程 | 第51条第1项 |
| 实施 分类 管理 + 加密 / 去标识化 | 第51条第2/3项 |
| 合理 确定 操作权限 + 培训 | 第51条第4项 |
| 制定 应急预案 + 应急响应 | 第51条第5项 |
| **委托 处理** (vendor management): 协议 约定 委托目的 / 期限 / 处理方式 / 个人信息种类 / 保护措施 / 双方权利义务; 监督 受托人 | 第21条 |
| **共同处理** (joint controllers): 约定 各自 权利义务 — 不能免除 个人 任一方 主张权利 | 第20条 |
| **个人信息保护 影响评估** (PIA, DPIA 中国版) | 第55-56条 — 处理 敏感 / 自动化 决策 / 委托 / 共同 / 提供 第三方 / 公开 / 跨境 都触发 |
| 处理 个人信息 数量 达到 国家网信部门 规定 → **指定 个人信息保护 负责人** (DPO) | 第52条 |
| 跨境 提供 → 评估 + 路径之一 (3 选 1) | 第38-43条 |
| 数据 安全事件 应急 + 通知 (个人 + 监管) | 第57条 |
| 大型 平台 (具有 重要影响力 / 用户数量 巨大 / 业务 类型 复杂) → 额外义务: 平台规则 / 公平公正 / 算法监督 / 重大 事件 报告 / 个人信息 保护 社会责任 报告 | 第58条 |

## Cross-Border Transfer (第38-43条)

### 4 Triggers for 评估
跨境 包括: 提供 给 境外 (实体) + 跨境 远程访问 + 境内 收集 + 境外 存储 等.

### 3 Compliance Routes (二选一 / 三选一)

| Route | When | Source |
|---|---|---|
| **数据 出境 安全评估** (CAC 评估) | 处理者 = 关键信息基础设施 运营者 / 数据 量 达到 国家网信办 规定 阈值 / 涉及 重要数据 等 | 《数据出境安全评估办法》(2022) + 2024 减负 |
| **个人信息 保护 认证** | 通过 国家 认可 机构 认证 | 实务 案例 较少 |
| **标准合同** | 普通 处理者 ↔ 境外接收方 签 国家网信办 制定的 标准合同 + 备案 | 《个人信息出境标准合同办法》(2023) |

### 2024 减负 (《促进和规范数据跨境流动规定》)
- 大幅 提高 触发 安全评估 阈值
- 自贸区 数据 跨境 负面清单 + 明清单 制度
- 减少 个人信息 跨境 评估 / 标准合同 触发 范围

**实务影响 (operator's 集团)**:
- 集团 业务 涉及 海外客户 (印染 出口 OEKO-TEX / GRS 客户 — 部分 在欧洲 / 日韩 / 美国) → 业务往来 含 客户联系人 个人信息 → 触发 跨境 (除非 仅 商务 公开 信息)
- 推荐: 评估 数据 量 + 选择 标准合同 (中等 规模) OR 安全评估 (大规模 / 涉及 敏感)

## Individual Rights (第44-50条) — 7 项

1. 知情 + 决定 (含 限制 / 拒绝)
2. 查阅 + 复制
3. 转移 (个人信息 可携带性 — 实务 落实 仍在发展)
4. 更正 + 补充
5. 删除
6. 解释 处理 规则
7. 死亡后 — 近亲属 行使 上述权利 (第49条)

## Liabilities and Penalties (第66-71条)

| Violation | Penalty |
|---|---|
| 一般 违反 — 没收 违法所得 + 责令 暂停 / 终止 | 警告 + 100 万 以下 罚款; 直接负责的 主管 + 其他直接责任人员 1 万 - 10 万 |
| **情节严重** | 责令 改正 + 没收 违法所得 + **5000 万 以下 OR 上一年度 营业额 5% 以下** 罚款 + 暂停 / 停业整顿 / 吊销 营业执照 (重大 后果); 主管 + 责任人 10 万 - 100 万 + 行业禁入 |
| 个人信息 处理 关联 民事 侵权 | 民法典 + PIPL — 损害赔偿 (第69条 — 处理者 应证明 自己没过错; 否则 担责) |
| 公益 诉讼 | 第70条 — 检察院 / 法律规定的 消费者组织 / 网信部门 确定的 组织 → 提起 公益 诉讼 |
| 行政 + 刑事 衔接 | 严重 → 触犯 刑法 第253条之一 侵犯公民个人信息罪 (3 年以下 / 3-7 年 + 罚金) |

## High-Frequency Use Cases for the Operator (Industry Side)

### Case A: 厂里 员工 个人信息 (HR / 考勤 / 工资 / 社保)
- 触发: 处理 员工 (姓名 / 身份证 / 银行账户 / 社保 / 健康体检) — 大量 PI + 部分 敏感 PI
- 法律基础: 第13条第2项 — 履行 劳动合同 + 实施 人力资源管理 (无需 单独同意, 但仍需 告知)
- 制度: 员工 隐私 政策 (告知) + 内部 数据 安全 制度 + 加密 + 培训 + 应急 + 委托 (HR SaaS / 工资 代发 银行) 协议

### Case B: 客户 / 业务 联系人 个人信息
- 触发: B2B 客户 联系人 (姓名 / 邮箱 / 电话) — 普通 PI; 财务负责人 银行账户 — 敏感 PI
- 法律基础: 第13条第2项 — 订立 / 履行 合同 所必需 + 第13条第1项 — 同意 (合同条款 OR 业务表单)
- 跨境: 海外 客户 — 必须 评估 PIPL 第38-43条 跨境 路径 + 标准合同

### Case C: 监控视频 / 门禁 / 厂区监控
- 触发: 视频 + 生物识别 (人脸 / 指纹) — 部分 敏感 PI
- 法律基础: (a) 安全 / 合规 / 公共利益 (但 必须 合理范围 + 公开 设置 + 告知)
- 储存 期限: 合理; 推荐 ≤30 日 (除非 法定 / 业务 合理 期限 更长)
- 公示: 监控区 入口 公示 — 必须

### Case D: 数据 安全事件 — 员工 信息 / 客户 信息 泄露
- 第57条 — 立即 采取补救; 通知 监管部门 + 个人; 不可避免地 / 重大 → 公告
- 实务: 准备 应急 预案 + 模拟演练; 律师 + 公关 + 监管联系人 提前 储备

### Case E: 个保 影响评估 (PIA / DPIA)
- 第55条 触发条件 7 类 — 操作员 集团 涉及 (a) 处理 敏感 个人信息 (员工 健康 / 客户 财务); (b) 委托 + 共同 + 提供 + 跨境
- 评估 报告 留存 ≥3 年
- 推荐: 标准化 PIA 模板 + 律所 / 安全咨询公司 协助 完成
