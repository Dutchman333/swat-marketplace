## What's Changed in 2024 Revision

| Item | 旧法 (2018) | 新法 (2024-07-01) |
|---|---|---|
| **认缴 vs 实缴** | 认缴制 (无法定 实缴期限) | 全体股东 认缴 出资额 自公司 成立之日起 **5 年内 缴足** (第47条 — LLC; 第98条 — JSC) |
| **过渡期** | — | 现存公司 国务院 规定 调整章程 + 实缴期 (一般 至 2027-06-30; 部分 可延期 至 2032 年) |
| **股东 出资 加速 到期** | 司法解释 / 案例 推定 | **第54条 法定** — 公司 不能清偿到期债务的, 公司 OR 已到期债权 的 债权人 有权要求 出资期限 未届满 的 股东 提前 缴纳 出资 |
| **法定代表人** | 必须 由 董事长 / 执行董事 / 经理 担任 | 第10条 — 法定代表人 由 代表公司 执行 公司 事务 的 董事 OR 经理 担任 (允许 经理 担任) |
| **董事会 / 审计委员会** | 须 监事会 (3 人以上) OR 监事 (50 人以下 LLC) | 第69 / 121条 — LLC 可在 董事会 中 设 审计委员会, 由 董事 组成, 行使 监事会 职权; 不再 设监事会 / 监事 (二选一) |
| **一人公司** | 旧法 第57-63条 — 特殊监管 + 财产混同 风险 | 第六节 (第99-103条) 整合 一人 LLC; 不再 单独成节 |
| **股东 知情权** | 公司法第33条 (LLC) | 第57条 — LLC 股东 查阅权 范围扩大: 股东会 / 董事会 / 监事会 决议 + 财务会计报告 + 会计账簿 + 会计凭证 |
| **关联交易 + 控股股东 / 实控人 责任** | 部分 隐性 | **第22条 + 第180-191条** — 控股股东 / 实控人 / 董监高 信义义务 (忠实 + 勤勉) 全面化; 第191条 — 控股股东 / 实控人 / 董监高 利用 关联关系 损害 公司利益 → 赔偿责任 |
| **股东压迫 / 异议股东 退出** | 公司法第74条 (LLC, 1+5+5 三种情形) | 第89条 — LLC 异议股东 异议 股东 有权 请求 公司 按 合理价格 收购 其股权; 同时 第89条第3款 — 控股股东 滥用 权利 严重损害 公司 / 其他股东 利益 → 其他股东 可请求 公司 收购 (新增 — 反 控股股东 压迫) |
| **公司 注销 + 清算** | 严 | 第三章 第三节 (第231-243条) — 简易注销 / 强制注销 整合 |

## LLC Governance Structure (operator's group is this)

```
股东会 (最高权力机关)
   │
   ├── 选举 + 罢免 董事
   ├── 选举 + 罢免 监事 (若 设监事会)
   ├── 审议 财务预算 + 决算
   ├── 审议 利润分配 + 弥补亏损
   ├── 增减 注册资本
   ├── 公司 合并 / 分立 / 解散 / 清算 / 公司形式 变更
   ├── 修改 章程
   └── 章程 规定的 其他 职权

董事会 (3-13 人) — 章程 可规定 不设董事会, 仅设 1 名董事 (新)
   │
   ├── 召集 股东会
   ├── 执行 股东会 决议
   ├── 决定 经营计划 + 投资方案
   ├── 制订 财务预算 + 决算 + 利润分配 等
   ├── 决定 内部管理机构 设置
   ├── 决定 聘任 / 解聘 经理
   └── 审计 委员会 (新, 替代 监事会 — 二选一)

监事会 (3 人以上) OR 监事 (1-2 人) — 二选一: 监事会 vs 审计委员会
```

## Capital Contribution — 5-Year Rule

第47条 (LLC):
"有限责任公司 的 注册资本 为 在 公司登记机关 登记的 全体股东 认缴的 出资额. 全体股东 认缴 的 出资额 自 公司成立之日起 五年内 缴足."

**关键 计算**:
- 新设 LLC: 公司成立日 + 5 年 = 必须 全部 实缴 完成
- 现存 LLC: 国务院 过渡期规定 — 一般 在 2027-06-30 前 调整章程; 调整后 实缴期 → 不超过 5 年 (从调整日 起算); 部分情形 (出资额 巨大 / 行业特殊) 可经 登记机关 评估 延长 至 2032

**操作员 集团 三家公司 — 必须 立即评估**:
- (1) 公司 章程 中 注册资本 + 已实缴 + 待实缴 现状
- (2) 国务院 过渡期 安排
- (3) 调整 章程 + 必要时 减资

**减资 程序** (第224条):
- 股东会 决议
- 编制 资产负债表 + 财产清单
- 通知债权人 (10 日内) + 公告 (45 日)
- 债权人 可要求 清偿 OR 担保

## Capital Contribution — Acceleration on Insolvency (新增 第54条)

第54条:
"公司 不能 清偿 到期债务 的, 公司 OR 已到期债权 的 债权人 有权 要求 已认缴出资 但 出资期限 未届满 的 股东 提前 缴纳 出资."

**实务影响**: 旧法下 股东 出资期限 未到 → 不实缴; 新法 下 公司 出现 不能清偿 → 股东 出资 加速到期 → 必须 实缴 → 个人 资产 责任 真实化.

## Director / Officer Fiduciary Duties (信义义务) — 全面化

| Duty | Articles | Content |
|---|---|---|
| 忠实义务 (Loyalty) | 第180条第1款 + 第181-185条 | 不得 利用 职务便利 谋取 不正当 利益 (8 项 具体 禁止 行为, 含 关联交易 / 商业机会 / 同业竞争 等) |
| 勤勉义务 (Care / Diligence) | 第180条第2款 | 应当 履行职务 时 尽到 通常 应有的 合理 注意 — business judgment rule 中国版 |
| 衍生诉讼 | 第189-190条 | 股东 可代表 公司 提起 衍生诉讼 — 监事会 / 监事 / 董事会 / 董事 拒绝 OR 30 日 未提起 → 股东 自身可起诉 (LLC: 任何 股东; JSC: 连续180日以上 单独 / 合计 ≥1% 股份) |

## Controlling Shareholder + Actual Controller Liability (新)

第22条 + 第191条:
- 第22条 — 控股股东 / 实际控制人 / 董事 / 监事 / 高管 不得 利用 关联 关系 损害 公司 利益; 否则 应当承担 赔偿责任
- 第191条 — 公司 董事 / 高管 执行职务 给 他人 造成 损害 → 公司 担责; 董事 / 高管 有 故意 OR 重大过失 → 与公司 一起 担责 (Pier-cing 反向 思路)

**Practitioner note**: 在 控股股东 / 实控人 与 (将来的) 接班人 关系 中 — 必须 警惕 关联交易 + 利益输送 风险 → 设独立董事 OR 审计委员会 监督 + 留痕 决策 程序.

## Shareholder Information Rights (扩大)

第57条 (LLC): 股东 有权 查阅 + 复制:
- 公司章程
- 股东名册
- 股东会会议记录
- 董事会会议决议
- 监事会会议决议 (若设)
- 财务会计报告
- 会计账簿
- **会计凭证 (新)** — 凭证 是 实务上 高敏感

**程序**: 股东 应当 向 公司 提出 书面 请求, 说明 目的. 公司 有 合理 根据 认为 股东 查阅 有 不正当 目的, 可能 损害 公司 合法权益 → 可以 拒绝 提供, 并 自股东 请求之日起 15 日内 书面答复. 股东 不服 → 可以 起诉.

## Equity Transfer (股权转让)

LLC 第84-89条:

**对内 转让**: 股东 之间 可以 相互转让 其 全部 OR 部分 股权 (第84条第1款) — 自由

**对外 转让** (第84条第2 / 3款):
- 股东 向 股东以外的人 转让 股权 → 应当 书面通知 其他股东 (征求 优先购买权)
- 其他股东 自接到 书面通知 之日起 30 日内 未答复 → 视为 同意; 过半数 股东 不同意 → 不同意 的 股东 应当 购买 该 转让的 股权; 不购买 → 视为 同意
- 同等条件 下 其他股东 享有 优先购买权
- 章程 可以 规定 不同 安排 — **章程 自治** 重要 工具

**继承** (第90条 — 第75条 调整后): 自然人股东 死亡后 → 其 合法继承人 可以 继承 股东资格; 但 章程 可以 限制 (排除) — 章程 排除 → 继承人 仅 主张 财产份额, 不取得 股东资格.

**Practitioner note (succession scenarios)**: 集团 多家 公司 章程 应 提前 修订:
- (a) 明确 自然人股东 死亡 + 继承人 (操作员) 可以 继承 股东资格
- (b) 转让 限制 — 控股 / 接班 股东 股权 转让 必须 经 其他股东 / 董事会 同意, 防止 第三人 进入

## Squeeze-Out Protection (新增 反 控股股东 压迫)

第89条第3款 (新增):
"控股股东 滥用 股东权利 严重损害 公司 OR 其他股东 利益 的, 其他股东 有权 请求 公司 按照 合理 价格 收购其 股权."

**Practitioner note**: 若 控股股东 行为 损害 小股东 (e.g. 兄弟姐妹 / 创业老员工 / 财务投资人) → 小股东 可主张 公司 回购. 是 平衡 工具.
