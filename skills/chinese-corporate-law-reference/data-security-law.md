# Data Security Law (DSL) — Practitioner Reference

> Statute: 《中华人民共和国数据安全法》(2021-06-10 通过, 2021-09-01 施行)
> Companions:
> - 《中华人民共和国网络安全法》(2017-06-01 施行) — 网络运营者 + 关键信息基础设施
> - 《中华人民共和国个人信息保护法》(PIPL, 2021-11-01 施行) — see `personal-information-protection-law.md`
> - 《数据出境安全评估办法》(2022-09-01 施行)
> - 《网络数据安全管理条例》(2024-09-30 公布, 2025-01-01 施行)
> - 《重要数据 + 核心数据 / 重要数据 处理 安全 国家标准》(GB/T 等系列, 部分 推荐性 国标)

## Scope (第3条)

**数据** = 任何 以电子 OR 其他方式 对 信息 的 记录.
**数据 处理** = 数据 收集 / 存储 / 使用 / 加工 / 传输 / 提供 / 公开 等.
**数据安全** = 数据 完整性 / 保密性 / 可用性 + 处理 全过程 安全.

> DSL 比 PIPL 范围 更广 — DSL 覆盖 所有 数据 (含 个人信息 + 非个人信息); PIPL 仅 个人信息.

## Data Classification (数据 分类分级)

第21条:
"国家 建立 数据 分类 分级 保护制度, 根据 数据 在 经济社会 发展 中的 重要程度, 以及 一旦 遭到 篡改 / 破坏 / 泄露 / 非法 获取 / 非法 利用, 对 国家 安全 / 公共利益 OR 个人 / 组织 合法权益 造成的 危害程度, 对 数据 实行 分类分级保护."

3 大类:
1. **一般 数据** — Default
2. **重要数据** — 由 国家 + 各地区 + 各部门 制定 重要数据 目录; 一旦 泄露 / 篡改 / 损毁 → 危害 国家安全 / 公共利益
3. **国家 核心数据** — 关系 国家安全 / 国民经济命脉 / 重要民生 / 重大公共利益 — 实行 更严格 管理制度

## Processor Obligations (第27-29条)

| Obligation | Source |
|---|---|
| 建立 数据 全流程 安全管理 制度 | 第27条 — 包括 收集 / 存储 / 使用 / 加工 / 传输 / 提供 / 公开 等 全过程 |
| 组织 数据 安全 教育 培训 | 第27条 |
| **重要数据** 处理者 → 设立 数据安全 负责人 + 管理机构 | 第27条第2款 |
| 处理 数据 应当 加强 风险监测; 发现数据安全缺陷 / 漏洞 → 立即 采取 补救措施; 数据 安全事件 → 立即 处置 + 通知 用户 + 监管 | 第29条 |
| **重要数据** 处理者 → 定期 风险评估 + 报告 | 第30条 |

## Cross-Border (第31条)

**关键 信息 基础设施** (CIIO) 运营者 在 中华人民共和国 境内 运营 中 收集 + 产生 的 重要数据 → 数据出境 安全评估 (网络安全法 第37条 + 数据出境 安全评估办法).

**其他数据 处理者** 重要数据 出境 → 同上 评估 (DSL 第31条 + 后续 配套办法).

> 详细 跨境 路径 见 `personal-information-protection-law.md` — DSL 与 PIPL 跨境 共同 适用.

## Outbound Data Provision Restrictions (第36条)

中华人民共和国 主管机关 依法 处理 数据 时, 境外 司法 / 执法机构 要求 提供 存储于 中华人民共和国 境内 的 数据 → 非经 中华人民共和国 主管机关 批准, 境内 组织 / 个人 不得 提供.

**实务 (operator)**: 海外 客户 / 政府 / 律师 要求 厂里 数据 → 必须 经 中国 主管机关 批准 才能提供 (e.g. 美国 / 欧洲 司法协助 请求).

## Liabilities and Penalties (第45-52条)

| Violation | Penalty |
|---|---|
| 未履行 数据安全 保护 义务 | 责令 改正 + 警告 (5 万 - 50 万) — 严重 (50 万 - 200 万 + 暂停 业务 / 停业整顿 / 吊销 许可证) |
| 重要数据 风险 评估 / 报告 漏 | 5 万 - 50 万 — 严重 50 万 - 200 万 |
| **未经批准** 向 境外 司法 / 执法机构 提供 数据 | 100 万 以下; 严重 → 100 万 - 500 万 + 暂停 / 停业整顿 / 吊销 许可证 |
| 危害 国家 安全 + 公共利益 + 公民 / 组织 合法权益 — 数据 处理活动 | 50 万 - 200 万 + 暂停 / 停业整顿 / 吊销 |
| 国家 核心数据 → 200 万 - 1000 万 + 追究 刑事责任 | — |
| 危害 国家 安全 / 公共利益 → 触犯 刑法 (e.g. 非法获取 国家秘密罪 / 非法 经营罪 / 等) | 与 PIPL / 网络安全法 衔接 |

## Network Data Security Regulations (2025-01-01 施行)

《网络数据安全管理条例》(2024-09-30 公布) 进一步细化:
- 网络数据 处理者 + 重要数据 处理者 安全管理 义务
- 网络数据 安全 监测 + 应急
- 重要数据 处理者 + 网络数据 处理 月数 + 年数 + 用户数 等触发 不同 监管 强度
- 跨境 提供 网络数据 + 国家 安全 审查
- 个人信息 + 网络数据 衔接

> 必查 — 2025 年起 重要 配套 行政法规.

## High-Frequency Use Cases for the Operator (Group / Industry Side)

### Case A: 集团 数据 资产 盘点 + 分类
- 步骤:
  (1) 数据 库存 — 列 所有 数据 (员工 / 客户 / 财务 / 生产工艺 / 配方 / 供应链 / IoT 设备 / 监控视频 / 等)
  (2) 分类 — 一般 / 重要 / (核心 — 通常不涉及, 但 印染 工艺 + 化学品 配方 可能 触及 行业 重要数据)
  (3) 分级 — 高 / 中 / 低 风险
  (4) 制度 — 全流程 安全管理 制度
- 推荐: 律师 + 数据 / 信安 顾问 联合; 1 次/年 复盘

### Case B: 染整 工艺 / 配方 数据 — 内部 + 商业秘密 双重保护
- 工艺 / 配方 = (a) DSL 重要数据 (印染 行业 — 可能 进入 行业 重要数据 目录); (b) 反不正当竞争法 商业秘密
- 双重 保护 措施: 加密 + 访问 控制 + 离职 员工 NDA + 离职 时 数据 清理 + 监控
- 详细 见 `anti-unfair-competition-and-trade-secret.md`

### Case C: IoT 设备 / 工艺 控制系统 数据
- 染色 设备 (高卷 / 溢流 / 汽流 / 卷染) 联网 → 大量 工艺 数据 + 设备 状态 数据 + 能耗 数据
- 触发: DSL + (网络安全法 — 若 是 关键信息基础设施 — 印染 一般 不属于 CIIO, 但 部分 大型 集团 可能 触发)
- 制度: 设备 网络 隔离 + 数据 加密 + 异常监测 + 应急

### Case D: 数据 安全 事件 应急
- 触发: 数据 泄露 (黑客 / 内部 / 第三方 供应商) — 客户 信息 / 员工 信息 / 工艺 配方 / 财务 数据
- 第29条 — 立即 处置 + 通知 + 监管报告
- 实务: 应急预案 + 模拟演练 + 律师 / 公关 / 监管联系人 储备 + 备份 + 灾难恢复

### Case E: 跨境 数据 — 海外 客户 业务往来
- 海外 客户 (欧洲 / 日韩 / 美国 / 东南亚 — OEKO-TEX / GRS / Higg 客户)
- 业务 往来 含: 客户 联系人 (PI) + 订单 (一般数据) + 验厂 报告 (一般数据 + 部分 敏感)
- 路径: 评估 量 + 类型 → 选 标准合同 (常见) OR 安全评估 (重要数据 / 大量 PI)
- 备案: 标准合同 → 网信办 备案
